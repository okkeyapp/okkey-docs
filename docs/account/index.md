# Аккаунт и устройства

Личные настройки и устройство открываются из меню аккаунта: «Мои настройки» и «Настройки устройства». «Мои настройки» - окно со своим адресом `?popup=settings`. Язык переключается в шапке веба. «Сменить сервер» есть в расширении.

Правила пространства открываются из пункта сайдбара «Настройки».
