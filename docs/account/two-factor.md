# Двухфакторная аутентификация {#двухфакторная-аутентификация}

Второй фактор нужен, чтобы кода из почты было мало для входа. Пункт меню «2ФА аутентификация», заголовок страницы «Двухфакторная аутентификация». Адрес: `?popup=settings|twoFactor`. Доступно на тарифе «Бесплатный» и на тарифе «Предприятие».

## Включить

1. Включите «Приложение-аутентификатор». Подпись: стороннее приложение, например Google Authenticator, выдаёт одноразовые коды.
2. Окно «Настройка аутентификатора»: «Отсканируйте QR-код в приложении-аутентификаторе или введите секретный код вручную». Поле «Секретный код», кнопки «Скопировать секретный код» и «Далее».
3. Окно «Подтверждение 2ФА»: «Введите 6-значный код из приложения-аутентификатора», поле «Код подтверждения», кнопка «Подтвердить».

Неверный код: «Неверный код подтверждения». Если сессия настройки истекла: «Сессия настройки истекла. Начните заново».

После подтверждения появляются «Резервные коды». Это одноразовые коды на случай, если приложения нет под рукой. По умолчанию их 10. На экране «Осталось кодов: N», «Скопировать» и «Скачать PDF». PDF называется «Резервные коды». Текст: каждый код можно использовать только один раз.

## Перегенерировать и выключить

«Перегенерировать» открывает «Перегенерация резервных кодов». Нужен код из приложения. Предупреждение: «После перегенерации кодов старые коды будут недействительны». Тост: «Резервные коды сгенерированы».

«Отключение 2ФА» просит код из приложения. Кнопка «Отключить».

## Как проверить

1. Включите «Приложение-аутентификатор», введите код из приложения и дойдите до «Резервных кодов». «Скачать PDF» сохраняет файл.
2. Выйдите и войдите снова. После кода из письма открывается «Двухфакторная аутентификация»: поле «2ФА код» и кнопка «Подтвердить». «Ввести резервный код» переключает на «Резервный код». Тот же резервный код второй раз не проходит.
3. «Отключить» с кодом из приложения выключает второй фактор. Следующий вход обходится кодом из письма.
