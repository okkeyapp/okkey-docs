# Браузерное расширение

Расширение называется «Okkey», описание в манифесте: `Okkey password manager extension`, версия `0.0.1`. Это Manifest V3, одна кодовая база для Chromium (Chrome, Edge, Opera, Yandex) и Firefox. Идентификатор Firefox: `extension@okkey.io`, минимальная версия Firefox `121.0`.

Готового магазинного листинга в репозитории нет. Ставится распакованная сборка. **TODO:** публикация в Chrome Web Store и Firefox Add-ons не описана.

## Сборка

Нужны Node `>=25 <26` (`.tool-versions` монорепозитория) и Yarn 1.22 из корня `okkey`.

```bash
yarn build:extension:chromium   # apps/extension/output/chrome-mv3
yarn build:extension:firefox    # apps/extension/output/firefox-mv3
```

Chromium: `chrome://extensions` или `edge://extensions`, режим разработчика, «Load unpacked», папка `apps/extension/output/chrome-mv3`.

Firefox: `about:debugging#/runtime/this-firefox`, «Load Temporary Add-on…», файл `apps/extension/output/firefox-mv3/manifest.json`. Временное дополнение Firefox пропадёт после перезапуска браузера - так устроен этот способ установки, отдельного постоянного пакета в репозитории нет.

Разрешения: `storage`, `tabs`, `idle`, доступ к сайтам `<all_urls>` (автозаполнение).

## Вход

1. В попапе укажите URL сервера. Для локальной разработки веб - `http://localhost:5173`, рядом должны работать API и web.
2. Вход открывает веб и PKCE. Веб-маршрут расширения не уводит в хранилище, пока передача сессии не закончена.
3. Новое устройство ждёт подтверждения на уже доверенном устройстве.
4. «Разблокировать» - тот же мастер-пароль, что в вебе.

«Выйти» и «Сменить сервер» стирают сессию, устройство и кэш сейфа расширения и оставляют только последний URL сервера.

## Что умеет попап

После разблокировки:

- шапка: меню, поиск по мере ввода, блокировка, «+» (открывает веб `/items?popup=newItem`);
- меню: переключатель пространства, сейфы без кнопки создания, папки без настроек папок, профиль с «Выйти» и «Сменить сервер». Пунктов «Настройки», «Документация» и «Помощь» в этом меню нет;
- список слева и карточка записи. Редактирование, капсула, избранное и архив уходят глубокими ссылками в веб. Копирование поля подчиняется очистке буфера.

В настройках устройства расширения сохраняются тема и PIN. Биометрия разблокировки расширения есть в коде клиента (`extensionBiometricUnlock`). **TODO:** полный паритет экрана «Разблокировка» веба и попапа расширения по каждому переключателю в этой документации не сверен построчно.

## Автозаполнение

Скрипт на странице подставляет логин, пароль и TOTP для категории «Логин / пароль». У поля «URL сайта» в секции сайтов три режима (шестерёнка поля):

- «Заполнять на всём сайте»
- «Заполнять только на этом URL»
- «Без автозаполнения»

Если хранилище расширения закрыто, оверлей показывает «Разблокировать». Копирование логина или пароля на вкладке, которая не совпадает ни с одним URL записи, спрашивает подтверждение. Предложение сохранить пароль со страницы в коде есть. Генератор пароля прямо на странице README расширения относит к ещё не сделанному шагу. **TODO:** не считать страничный генератор доступным.
