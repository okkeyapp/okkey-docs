# Капсулы

Капсула передаёт текст, файл или запись по ссылке. Содержимое шифруется на вашем устройстве. Получатель видит только то, что разрешила карточка.

Пункт сайдбара «Капсулы». Капсула есть на Free и на Enterprise.

На Free это ссылка без расширенных настроек доступа. На Enterprise доступен блок «Расширенные настройки»: лимит просмотров, срок, список получателей, пароль и подтверждение владельца.

Политики пространства могут сделать часть этих настроек обязательными. Их задают в [настройках капсул](./settings/workspace#капсулы). Если участнику запрещено создавать капсулы, пункт для него закрыт.

## Список

Кнопка «Создать капсулу». Поиск ищет по названию.

Колонки: «Название», «Тип», «Создан», «Изменён», «Активен», «Просмотров», «С паролем». Тип: «Текст», «Файл», «Запись».

Строку можно выделить. Доступны деактивация, активация, удаление и копирование ссылки.

Удаление окончательное: капсула не попадает в корзину записей, ссылка перестаёт работать.

## Новая капсула

Окно «Новая капсула» или «Редактирование капсулы». Поле «Название».

Содержимое:

- текст;
- файл, с лимитами файлов пространства;
- запись. Поиск ищет по открытым полям, не по секретам. Можно отдать все поля, все кроме выбранных или только выбранные.

«Расширенные настройки» показывают, сколько блоков включено.

| Блок | Что задаётся |
| --- | --- |
| «Просмотры» | Число просмотров и действие после лимита: «Деактивировать» или «Удалить капсулу». |
| «Время» | Когда включить, выключить и удалить капсулу. Можно выбрать готовый срок или дату. Выключение раньше включения сохранить нельзя. |
| «Доступ» | Кто может открыть ссылку. Чужой email можно добавить. |
| «Пароль» | Пароль просмотра и число неудачных попыток. При правке пустое поле оставляет прежний пароль. |
| «Подтверждение» | Показ ждёт решения владельца. В заявке видны устройство, система, страна, город и время. Кнопки: «Одобрить», «Запретить показ». Можно добавить email или IP в чёрный список этой капсулы. |

«Установить эти настройки по умолчанию для меня» запоминает блоки для следующих капсул.

Если политика пространства уже включила блок, снять его в карточке нельзя.

:::tip
На Free капсула создаётся без «Расширенных настроек». Лимиты, пароль и список получателей появляются на Enterprise.
:::

## Ссылка для получателя

Страница капсулы открывается без входа в хранилище. Получатель видит пароль, ожидание одобрения, лимит просмотров или срок - то, что включено в карточке.

Страна и город заявки появляются, если на сервере включено определение места. В обычной установке оно выключено, тогда страна и город остаются неизвестными.

Сервер хранит шифротекст и правила доступа.
