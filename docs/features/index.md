# Возможности

Ядро Okkey строится вокруг четырёх свойств, которые зафиксированы в архитектуре и в криптокоде, а не только в маркетинговом тексте.

- [Q-Day ready](./qday) — постквантовая готовность профиля v2.
- [Максимальная защищённость](./security) — разделённый ключ, отдельные ключи сейфов, клиентский AEAD.
- [Нулевое хранение](./zero-knowledge) — сервер хранит шифротекст и метаданные, не открытые секреты.
- [Открытый код, включая шифрование](./open-source) — Rust-движок и клиенты в репозитории `okkey`.

Пункты меню продукта, которые опираются на эти свойства: «Все записи», «Капсулы», «Мониторинг», «Инструменты», «Настройки».
