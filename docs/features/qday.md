# Q-Day ready

Новые записи шифруются гибридно: классическая схема и постквантовая. Более слабый профиль для новых записей не используется. Тариф Enterprise это шифрование не меняет.

Так запись остаётся защищённой, даже если одна из схем со временем ослабнет.

## Чем шифруются данные

- Мастер-пароль превращается в ключ через Argon2id.
- Содержимое записей, вложения и капсулы шифруются XChaCha20-Poly1305.
- В гибридной защите участвуют X25519 и ML-KEM-768.
- Важные действия с доступом к сейфу подписываются Ed25519 вместе с постквантовой привязкой.

Шифрование выполняется на вашем устройстве.
