# Максимальная защищённость

Записи шифруются у вас на устройстве. Сервер аутентифицирует, синхронизирует события и хранит шифротекст. Открытый текст записей и целый ключ сейфа ему не отдаются. Поэтому администратор сервера не читает сейф.

## Разделённый ключ

Ключ доступа собирается из трёх долей. В транспорте v1 операция «сложения» - побайтовый XOR 32 байт: `VaultKey = A ⊕ B ⊕ C`.

| Доля | Где лежит |
| --- | --- |
| A, server share | В базе, поле `server_key_share` пользователя. Это не весь ключ. |
| B, device share | На устройстве. В архитектуре: iOS Keychain, Android Keystore, десктоп - защищённое хранилище ОС, веб - IndexedDB и WebCrypto. |
| C, password share | `Argon2id` от мастер-пароля. Рядом на сервере хранятся соль и версия KDF, не сам пароль. |

Открытие хранилища идёт так:

1. Клиент забирает долю сервера.
2. Читает долю устройства.
3. Выводит долю пароля.
4. Собирает ключ и расшифровывает приватный ключ пользователя, затем ключи сейфов.

У пользователя есть пара ключей. Приватный ключ хранится зашифрованным ключом хранилища. Это нужно для шаринга, подтверждения устройства и приглашений.

## Ключи сейфов и записей

У каждого сейфа свой ключ. Записи внутри сейфа шифруются ключом сейфа (конверт XChaCha20-Poly1305: nonce и ciphertext с тегом). Вложения шифруются отдельным ключом и лежат в объектном хранилище уже в зашифрованном виде.

Поворот ключа обязателен при смене доступа. Для активных получателей поворот идёт через гибридный rewrap.

## Что ещё ограничивает доступ

- Новое устройство не становится доверенным, пока его не подтвердят.
- Вход по email: одноразовый код на почту. На пустой базе self-hosted код для первого аккаунта пропускается.
- Двухфакторная аутентификация в ядре: «Приложение-аутентификатор» и «Резервные коды».
- Разблокировка хранилища - мастер-пароль. На устройстве можно включить PIN из 6 цифр и биометрию. Эти секреты не синхронизируются.
- Для отдельных зон можно заново спрашивать мастер-пароль. Зоны: «Записи», «Капсулы», «Мониторинг», «Инструменты», «Настройки хранилища», «Мои настройки», всплывающие окна записей, капсул, сейфов и папок, действие «Удаление».
- Профили пространства режут просмотр категорий, полей и функций записи. Роли режут разделы настроек.

Мониторинг паролей считается на устройстве. Проверка утечек уходит в Have I Been Pwned только префиксом SHA-1. Полный пароль устройство не отправляет. Подробнее в разделе [Мониторинг](../monitoring).
