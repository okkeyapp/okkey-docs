# Предприятие

Тариф «Предприятие» — это self-hosted с большим набором функций. Ставите Okkey вы сами, по странице [Этапы установки](./free.md). Тариф после этого подключает сотрудник Okkey.

Это бета. Независимого аудита безопасности пока не было.

## Что даёт тариф

Цифры и полный список — на странице [Тарифы](../plans.md). Коротко, чем «Предприятие» отличается от тарифа «Бесплатный»:

| Возможность | «Предприятие» |
| --- | --- |
| Дополнительные участники | без предела |
| Общие сейфы | без предела |
| Мониторинг | да |
| Пользовательские роли и профили | да |
| Доверенные устройства и доверенные контакты | да |
| Расширенные настройки капсулы: срок, пароль и число попыток, доступ только участникам, подтверждение владельца | да |

Капсулы, файлы в записях, встроенные роли и профили, ключ восстановления, генератор, импорт и экспорт есть и на тарифе «Бесплатный». Потолка объёма хранилища на self-hosted нет уже на тарифе «Бесплатный».

На карточке в «Сменить тариф» среди строк есть «Неограниченное хранилище». Сравнивайте возможности по таблице на странице [Тарифы](../plans.md).

## Как запросить

1. Откройте «Настройки», «Сменить тариф». Кнопка «Отправить заявку» открывает окно «Заявка на лицензию». Текст окна: «Команда Okkey свяжется с вами по поводу лицензии для self-hosted.»
2. Укажите «Email для связи» и «Количество участников пространства». Нажмите «Отправить».

Письмо уходит на адрес `OKKEY_SALES_EMAIL` из файла `.env`. Его задают при [установке](./free.md). С одного пространства Okkey принимает не больше 3 заявок за скользящие 24 часа. Подробнее, включая тексты ошибок, на странице [Сменить тариф](../workspace/plan.md).

Ключ лицензии и портал лицензий планируются. Сейчас их нет: тариф подключает сотрудник Okkey.

## Обновления

Образы Okkey обновляются так же, как на тарифе «Бесплатный». Шаги — на странице [Обновление](../admin/upgrade.md).

В интерфейсе владелец может увидеть «Доступно обновление» и окно «Обновление системы». В окне отдельные строки «Okkey» и «Enterprise». Установка начинается после кнопки «Обновить». Применить обновление может только владелец. Если лента не задана, окно пишет: «Лента обновлений не задана. Можно применить файл пакета.» Пакет без действительной подписи не применяется. Если обновление не удалось, экземпляр остаётся на прежней версии.

## Когда лицензия заканчивается

Пространство переходит на тариф «Бесплатный». Данные остаются доступными. Общие сейфы и участники работают в пределах тарифа «Бесплатный»: один общий сейф и до 10 дополнительных участников. Функции тарифа «Предприятие» (расширенные настройки капсулы, пользовательские роли и профили, доверенные устройства и контакты, мониторинг) перестают получать обновления. Их можно просматривать и удалять, но создавать новое и менять существующее нельзя.

Тот же текст на странице [Тарифы](../plans.md#когда-лицензия-enterprise-заканчивается).

## Как проверить

Пока тариф «Бесплатный», в сайдбаре нет «Мониторинг», а в «Сменить тариф» видна карточка «Предприятие» и кнопка «Отправить заявку». После подключения тарифа заголовок блока: «Текущий тариф: Предприятие».
