# Первая настройка

Первый аккаунт создаётся без письма. Пока таблица `users` пустая, `POST /auth/email/start` возвращает `bootstrapRequired: true` и `authStateId`. Веб пропускает код из письма и открывает регистрацию. SMTP для первого аккаунта не нужен.

Как только пользователь появился, тот же адрес проходит обычный одноразовый код.

## Экраны

1. «Добро пожаловать в Okkey». Поле «Email», кнопка «Войти». Под кнопкой - согласие с «Политикой конфиденциальности».
2. Если база уже не пустая: «Код подтверждения», 6 цифр, «Отправить снова», «Войти с другим email».
3. «Регистрация в Okkey». Поля: «Имя», «Фамилия», «Мастер-пароль», «Повторите мастер-пароль». Подсказка мастер-пароля: «Это единственный пароль, который вам нужно запомнить. С его помощью вы будете входить в хранилище.» Чеклист «Перед регистрацией»: все поля заполнены, пароль не короче 4 символов (`MIN_MASTER_PASSWORD_LENGTH`), пароли совпадают. Кнопка «Зарегистрироваться».
4. «Сохраните ключ восстановления». Можно «Скопировать» или «Скачать PDF». Текст предупреждает, что после «Далее» ключ больше не покажут и сервер его не восстановит. Если запись ключа не удалась, интерфейс говорит настроить его позже: Настройки → Восстановление.

:::warning
Сохраните ключ восстановления до кнопки «Далее». После этого экран его больше не покажет, и сервер восстановить ключ не сможет.
:::

Регистрация создаёт личное пространство с именем «Личный» и «Личный сейф». В self-hosted у владельца одно пространство, второе создать нельзя. Новое пространство получает Free, если `ENTERPRISE_MODULES=false` или переменная не задана, и Enterprise при `ENTERPRISE_MODULES=true`.

Дальше откроется хранилище. Повторный вход на этом устройстве - экран разблокировки мастер-паролем («Мастер-пароль»). Пункты меню аккаунта: «Мои настройки», «Настройки устройства», «Выйти», «Сменить сервер», «Язык: …».
