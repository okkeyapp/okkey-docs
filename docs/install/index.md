# Установка self-hosted

Self-hosted ставит Okkey на вашу машину. Шифрование остаётся на клиенте, поэтому администратор сервера не читает сейфы.

Новое пространство получает Free, если `ENTERPRISE_MODULES=false` или переменная не задана. При `ENTERPRISE_MODULES=true` оно получает Enterprise. Что входит в каждый тариф, смотрите на странице [Тарифы](../plans).
