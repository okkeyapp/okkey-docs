# Установка self-hosted

Self-hosted ставит открытое ядро Okkey на вашу машину. Шифрование остаётся на клиенте: администратор сервера не читает сейфы.

Cloud-тарифы к этой установке не относятся: SaaS собирается из образов Enterprise, а их репозиторий при написании сайта был недоступен. **TODO:** пошаговая установка cloud в открытом коде не описана.
