# Установка self-hosted

Self-hosted ставит открытое ядро Okkey на вашу машину. Шифрование остаётся на клиенте: администратор сервера не читает сейфы. Без модулей новое пространство получает тариф Free. С `ENTERPRISE_MODULES` — Enterprise. Подробности — на странице [Тарифы](../plans).
