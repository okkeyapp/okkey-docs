# Установка self-hosted

Self-hosted ставит открытое ядро Okkey на вашу машину. Шифрование остаётся на клиенте: администратор сервера не читает сейфы.

Cloud-тарифы к этой установке не относятся. Пошаговой установки SaaS в `deploy/docker` нет. **TODO:** как конечному пользователю поднять облачный инстанс, в открытых инструкциях не описано.
