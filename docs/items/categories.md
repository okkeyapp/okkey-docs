# Категории и шаблоны

Категория задаёт, какие поля появятся в новой записи. Так вы не собираете логин или карту с нуля. Окно новой записи группирует категории так:

1. «Избранные категории» - если в избранном что-то есть.
2. «Шаблоны» - если вы сохраняли свои шаблоны. Блок стоит перед группой авторизации.
3. «Авторизация».
4. «Финансы».
5. «Личные данные».

«Защищённые файлы» видны, когда в пространстве включено «Разрешить файлы в записях». Эта настройка есть на Enterprise. Как её включить - в [настройках записей](../settings/workspace#записи).

## Избранное и порядок

По умолчанию в избранном, в таком порядке: «Логин / пароль», «Защищённая заметка», «Банковская карта», «Личные данные», «Паспорт», «Защищённые файлы».

Кнопка «Изменить порядок» (на узком экране «Сортировать») включает перетаскивание. «Готово» выходит из режима. Звезда добавляет и убирает категорию или шаблон из избранного.

## Группа «Авторизация»

Порядок в группе - порядок объявления в каталоге.

### Логин / пароль

Поля логина и сайтов:

| Поле | Тип | Обязательное | Можно удалить | Подпись можно менять |
| --- | --- | --- | --- | --- |
| «логин (емейл)» | текст | да | нет | нет |
| «пароль» | пароль, секрет | да | нет | нет |
| «URL сайта» | URL | да | нет у первого | да |

У URL по умолчанию «Заполнять на всём сайте». Ещё URL добавляет кнопка «Добавить URL». TOTP в пресете нет, его добавляют отдельно («Добавить TOTP»), если он нужен.

### API-доступ

| Поле | Тип | Обязательное | Удаляется |
| --- | --- | --- | --- |
| «имя» | текст | да | нет |
| «данные для входа» | секрет, однострочный | да | нет |
| «тип» | выбор | нет | да |
| «название файла» | текст | нет | да |
| «начало действия» | дата | нет | да |
| «окончание действия» | дата | нет | да |
| «название хоста» | текст | нет | да |

Пункты «тип»: «Данные для входа JSON», «Токен JSON Web», «Токен носителя», «Другое».

### База данных

Одна секция. Все поля можно удалить и переименовать.

| Поле | Тип |
| --- | --- |
| «тип» | выбор |
| «сервер» | текст |
| «порт» | текст |
| «база данных» | текст |
| «имя пользователя» | текст |
| «пароль» | секрет, вид «Пароль» |
| «SID» | текст |
| «псевдоним» | текст |
| «параметры подключения» | текст |

Пункты типа: PostgreSQL, MySQL, Microsoft SQL Server, Oracle Database, SQLite, MongoDB, Redis, Apache Cassandra, Elasticsearch, Snowflake, ClickHouse, «Другая».

### Сервер

Секция сервера: «URL адрес», «логин», «пароль» (секрет). Дополнительная секция «Админ консоль»: «URL адрес консоли», «логин консоли», «пароль консоли». Все эти поля удаляемые.

### Wi‑Fi роутер

Поля удаляемые: «имя станции», «пароль станции», «сервер / IP-адрес», «AirPort ID», «имя сети», «протокол безопасности сети» (выбор), «пароль сети», «пароль подключенного хранилища».

Протокол: WEP, WPA, WPA2-Enterprise, WPA2-Personal, WPA3-Enterprise, WPA3-Personal, «Без защиты».

## Группа «Финансы»

### Банковская карта

Одна секция. Не удаляются и не переименовываются:

| Поле | Тип | Обязательное |
| --- | --- | --- |
| «номер карты» | карта | да |
| «срок действия» | срок карты | да |
| «CVC/CVV-код» | pin | да |
| «владелец карты» | текст | нет |

У CVC меню поля: «Показать CVC/CVV» / «Скрыть CVC/CVV».

### Банковский счёт

Секция счёта, поля можно удалить и переименовать: «название банка», «имя владельца счёта», «номер счёта», «код SWIFT», «номер IBAN».

Дополнительная секция «Реквизиты банка»: «адрес банка» (текст), «телефон банка» (телефон). Тоже удаляемые.

### Криптокошелёк

Секция доступа, поля-секреты однострочные, удаляемые: «пароль доступа / PIN-код», «парольная фраза (Passphrase)».

Дополнительная секция «Кошелёк»: «адрес кошелька».

## Группа «Личные данные»

Порядок в группе задан отдельно: «Личные данные», «Паспорт», «Защищённые файлы», «Защищённая заметка».

### Личные данные

Секция личных данных. Поля пресета не удаляются и не переименовываются. Проверка формы требует «имя» и «фамилия». Остальные: «отчество», «пол», «дата рождения», «телефон», «емейл», «никнейм», «адрес».

«пол» - выбор: «Мужской», «Женский».

Секция «Работа»: «компания», «отдел», «должность», «рабочий телефон», «рабочий емейл».

Поле «инициалы» из шаблона убрано. Если оно осталось в старой записи, список всё ещё может показать его в описании строки.

### Паспорт

Секция паспорта, поля пресета: «тип», «страна выдачи», «серия номер», «полное имя», «пол», «национальность», «орган, выдавший документ», «дата рождения», «место рождения», «дата выдачи», «срок действия».

### Защищённые файлы

Одно поле файла. Категория появляется, когда включено «Разрешить файлы в записях». Сама настройка есть на Enterprise.

### Защищённая заметка

Одно поле «заметка».

## Шаблоны

Шаблон сохраняет категорию и набор полей, чтобы следующую такую запись не собирать заново.

«Сохранить как шаблон» просит название и может сразу добавить шаблон в избранное. После сохранения он появляется в блоке «Шаблоны».

Уже сохранённый шаблон обновляется в окне «Обновить шаблон». После сохранения в списке категорий лежит новая версия этого шаблона.
