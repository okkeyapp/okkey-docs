# Записи

Запись - это логин, карта, заметка или другой секрет внутри сейфа. «Все записи» в сайдбаре и кнопка «Добавить записи» открывают каталог категорий. Запись лежит в сейфе, может лежать в папке, имеет категорию, секции и поля.
