# Мониторинг

«Мониторинг» есть в боковом меню на Enterprise. Он показывает слабые и повторяющиеся пароли. Подсчёт идёт на вашем устройстве, сами пароли на сервер не отправляются. На карточке бейдж «Beta».

На Free этого пункта нет. Чтобы получить Enterprise, напишите команде Okkey. См. [Тарифы](./plans).

Оценка строится по записям, которые вам доступны в текущем пространстве.

Если паролей нет, страница предлагает перейти к записям. Если проблемы не нашлись, показано «Всё в порядке».

«Показать» открывает список записей с уже выбранным фильтром. Область сейфов: «Все сейфы», «Личный», «Общие».

По умолчанию видны все карточки: общий показатель, надёжность, повторы, слабые, скомпрометированные, устаревшие, passkeys и 2FA. Выключенная карточка не снижает оценку и не открывает список.

## Общий показатель

Оценка от 0 до 100. Подписи: от 90 «Отлично», от 70 «Хорошо», от 45 «Средне», ниже «Плохо».

Штраф берётся от доли проблемных паролей. Выключенный тип карточки в штраф не входит.

| Проблема | Снимается до |
| --- | --- |
| Слабые | 40 |
| Средние | 15 |
| Повторно используемые | 25 |
| Устаревшие | 15 |
| Скомпрометированные | 35 |

Пробелы 2FA и passkeys в эту оценку не входят.

## Карточки

Считаются пароли из записей, которые не в архиве и не удалены, в выбранных сейфах.

| Карточка | Когда запись попадает в список |
| --- | --- |
| «Надёжность паролей» | Доли сильных, средних и слабых паролей. Слабый пароль короткий или собран из простых шаблонов. |
| «Повторно используемые пароли» | Один и тот же пароль в двух и более записях. |
| «Слабые пароли» | Пароли, которые проще подобрать. |
| «Скомпрометированные пароли» | Пароль найден в известных утечках. Уходит только начало хеша, сам пароль устройство не отправляет. |
| «Устаревшие пароли» | Пароль не менялся больше года. |
| «2FA доступны, но не настроены» | У записи есть пароль, нет одноразового кода, а сайт из URL поддерживает второй фактор. Если справочник сайтов пуст, список тоже пуст. |
| «Passkeys доступны, но не настроены» | Карточка есть в списке. Записей в ней сейчас нет. |

:::warning
Список passkeys пустой. «Показать» по этой карточке откроет пустой список записей.
:::

«Показать» ставит фильтр списка. В обычном меню фильтра этих пунктов нет: они приходят со страницы мониторинга. См. [Списки записей](./lists).
