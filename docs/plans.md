# Тарифы

Документация описывает self-hosted. У пространства два тарифа.

| Бейдж | `plan_tier` | Когда ставится |
| --- | --- | --- |
| Бесплатный / Free | `FREE` | `ENTERPRISE_MODULES` выключен. Так регистрируется новое пространство. |
| Предприятие / Enterprise | `ENTERPRISE` | `ENTERPRISE_MODULES=true`. Так регистрируется новое пространство. |

Неизвестная строка `plan_tier` приводится к `FREE`.

Функции проверяет `hasPlanFeature(planTier)`. Плагины `okkey-enterprise` загружаются только при `ENTERPRISE_MODULES=true`. На новой установке это совпадает: без модулей tier `FREE` и плагинов нет, с модулями tier `ENTERPRISE` и плагины есть. Как включить модули — в [установке](./install/self-hosted#модули-enterprise).

В self-hosted у владельца одно пространство.

## Что включено

Флаги из `PLAN_FEATURE_MATRIX` для `FREE` и `ENTERPRISE`.

| Возможность | Free | Enterprise |
| --- | --- | --- |
| Капсулы | да | да |
| Настройки доступа капсулы | нет | да |
| Файлы в записях | нет | да |
| Мониторинг | нет | да |
| Восстановление через доверенные устройства | нет | да |
| Доверенные контакты | нет | да |
| Общие сейфы | нет | да |
| Дополнительные участники | нет | да |
| Свои роли | нет | да |
| Свои профили | нет | да |

Ключ восстановления (не устройства и не контакты) есть на обоих тарифах. Встроенные роли «Владелец», «Админ», «Пользователь» и встроенные профили «Простой» и «Расширенный» ядро показывает само. Свои роли, свои профили, приглашения, общие сейфы и мастера восстановления подключают плагины Enterprise.
