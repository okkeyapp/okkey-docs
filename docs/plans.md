# Тарифы

У self-hosted два тарифа: Free и Enterprise. Файлы в записях и мониторинг есть на обоих. Тариф решает, можете ли вы приглашать людей, делиться сейфами и включать расширенное восстановление.

Вы ставите Okkey сами. Такая установка работает на Free.

Enterprise настраивает сотрудник Okkey. Чтобы получить Enterprise, напишите команде Okkey.

Когда лицензия Enterprise заканчивается, включается мягкая блокировка. Всё, что вы уже создали, остаётся доступным. До продления в функциях Enterprise нельзя создавать новое и менять существующее, можно только удалять, и обновления Enterprise не приходят.

В self-hosted у владельца одно пространство.

## Что входит

| Возможность | Free | Enterprise |
| --- | --- | --- |
| Капсулы | да | да |
| Расширенные настройки | нет | да |
| Разрешить файлы в записях | да | да |
| Мониторинг | да | да |
| Ключ восстановления | да | да |
| Доверенные устройства | нет | да |
| Доверенные контакты | нет | да |
| Общие сейфы | нет | да |
| Дополнительные участники | нет | да |
| Встроенные роли («Владелец», «Админ», «Пользователь») | да | да |
| Пользовательские роли | нет | да |
| Встроенные профили («Простой», «Расширенный») | да | да |
| Пользовательские профили | нет | да |
