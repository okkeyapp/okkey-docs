# Тарифы

У self-hosted два тарифа: Free и Enterprise. Вы ставите Okkey сами, и такая установка работает на Free. Enterprise подключает сотрудник Okkey. Чтобы получить Enterprise, напишите команде Okkey из раздела [«Сменить тариф»](./workspace/plan.md).

В self-hosted у владельца одно пространство. Это верно и на Free, и на Enterprise.

## Что входит

Цифры ниже взяты из матрицы тарифов self-hosted. Личный сейф в предел общих сейфов не входит. Владелец в предел участников не входит.

| Возможность | Free | Enterprise |
| --- | --- | --- |
| Капсулы, включая файл | да | да |
| Файлы в записях | да | да |
| Лимит просмотров капсулы из настроек пространства | да | да |
| Расширенные настройки капсулы: срок, пароль и число попыток, доступ только участникам, подтверждение владельца | нет | да |
| Встроенные роли («Владелец», «Админ», «Пользователь») и профили («Простой», «Расширенный») | да | да |
| Пользовательские роли и профили | нет | да |
| Ключ восстановления | да | да |
| Доверенные устройства и доверенные контакты | нет | да |
| Общие сейфы | 1 | без предела |
| Дополнительные участники | 10 | без предела |
| Генератор, импорт и экспорт | да | да |
| Мониторинг | нет | да |
| Потолок объёма хранилища | нет | нет |

На карточке Enterprise в «Сменить тариф» среди строк есть «Неограниченное хранилище» и «Приоритетная поддержка». Потолка объёма на self-hosted нет уже на Free. Сравнение возможностей смотрите в таблице выше.

## Когда лицензия Enterprise заканчивается

Ничего не переносится на Free. Данные остаются доступными. Функции Enterprise перестают получать обновления. Создавать в них новое и менять существующее нельзя. Удалять можно.

## Как проверить

1. На Free в сайдбаре нет «Мониторинг». В «Настройки», «Сейфы» можно создать один общий сейф, второй не сохраняется.
2. В «Участники» приглашение проходит, пока дополнительных участников и живых приглашений не больше 10.
3. В «Роли» и «Профили» видны встроенные строки. Блок пользовательских ролей и профилей пишет, что функция недоступна на текущем тарифе.
4. В «Мои настройки», «Восстановление» есть «Ключ восстановления». «Доверенные устройства» и «Доверенные контакты» на Free не включаются.
