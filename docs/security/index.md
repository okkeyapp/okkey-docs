# Возможности

Свойства ниже объясняют, почему сервер не читает ваши записи.

- [Q-Day ready](./qday.md) - гибридное шифрование новых записей, с постквантовой частью.
- [Максимальная защищённость](./keys.md) - ключ из трёх долей, отдельный ключ у каждого сейфа.
- [Нулевое хранение](./zero-knowledge.md) - сервер хранит шифротекст, открытые секреты остаются у вас.
- [Утечка базы сервера](./server-db-leak.md) - с 1.0.0-beta.3 дамп базы или бэкапа сервера не позволяет перебирать мастер-пароль офлайн.
- [Открытый код, включая шифрование](./open-source.md) - шифрование опубликовано вместе с Okkey.

Пункты меню: «Все записи», «Капсулы», «Инструменты», «Настройки». «Мониторинг» есть на Enterprise.
