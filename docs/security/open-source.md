# Полностью открытый код, включая шифрование

Шифрование Okkey опубликовано. Его можно прочитать в открытом репозитории [okkeyapp/okkey](https://github.com/okkeyapp/okkey).

Там же лежат веб, мобильное приложение, десктоп, расширение браузера и установка через Docker. Поддерживается только Docker Compose. Kubernetes и Helm запланированы и не входят в v1.0.0.

Обзоры: [Q-Day ready](./qday.md), [Защищённость](./keys.md).

Enterprise настраивает сотрудник Okkey. Тариф меняет доступные функции пространства и не подменяет шифрование.

На Free есть встроенные роли и встроенные профили. Пользовательские роли, пользовательские профили, дополнительные участники и общие сейфы появляются на Enterprise. В self-hosted у владельца одно пространство.
