# Утечка базы или бэкапа сервера

:::note
с 1.0.0-beta.3
:::

Ключ хранилища собирается на вашем устройстве из трёх долей и нигде не хранится целиком.

- Доля сервера хранится на сервере. Одной этой доли недостаточно, чтобы открыть сейф.
- Доля устройства на сервере хранится только в запечатанном виде. Открыть её можно ключом, который остаётся на устройстве.
- Доля пароля считается из мастер-пароля на устройстве. Сам пароль и эта доля на сервер не уходят.

Поэтому утечка базы или бэкапа сервера не позволяет перебирать мастер-пароль офлайн. В дампе есть шифротекст записей и доля сервера, но без доли устройства ключ хранилища не собрать, и по дампу нельзя проверить угаданный пароль.

Это не значит, что сейф защищён во всех ситуациях.

- Если злоумышленник полностью контролирует сервер и подменяет веб-клиент, он может получить мастер-пароль или ключ, когда вы открываете хранилище в браузере.
- От вредоносной программы на вашем устройстве эта схема не защищает.

Это бета. Независимого аудита безопасности пока не было.
