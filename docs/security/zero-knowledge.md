# Нулевое хранение

Сервер не видит расшифрованные записи, мастер-пароль и целый ключ хранилища. Шифрование и расшифровка выполняются на вашем устройстве. Администратор сервера тоже не читает содержимое сейфов.

Как проходят данные сейфа:

1. Устройство шифрует запись.
2. Сервер сохраняет шифротекст.
3. Устройство расшифровывает запись, когда вы открываете хранилище.

## Что лежит на сервере

- Учётные записи, устройства и сведения о сейфах.
- Сессии и очередь писем.
- Зашифрованные файлы.

С 1.0.0-beta.3 доля устройства на сервере хранится только в запечатанном виде. Утечка базы или бэкапа сервера не позволяет перебирать мастер-пароль офлайн. Подробнее на странице [Утечка базы сервера](./server-db-leak.md).

Код входа сервер создаёт и отправляет на почту. Если почта не настроена, код виден в логах фоновых задач. Код входа к содержимому сейфа не относится.

Для капсул страна и город заявки, если эта функция включена, считаются на самом сервере. Адрес заявителя третьей стороне не отправляется. В обычной установке эта функция выключена.

Проверка утёкших паролей отправляет только начало хеша. Полный пароль в запросе не участвует.

Тариф Enterprise шифрование не меняет.
