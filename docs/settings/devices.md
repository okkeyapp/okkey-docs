# Устройства

Здесь два разных списка, и их легко перепутать. «Мои устройства» - учётные доверенные устройства аккаунта, они синхронизируются. «Настройки устройства» - только этот браузер. В подписи прямо сказано: «Эти параметры применяются только к текущему браузеру на этом устройстве и не переносятся на другие устройства.»

Старый пункт меню `deviceSettings` открывает «Персонализация».

## Мои устройства

Пункт «Мои устройства». Текст: «Устройства, способные открыть Ваше хранилище. Также устройства могут восстановить доступ к аккаунту если был утерян мастер-пароль».

Неподтверждённое устройство показывается как «Новое устройство». Его нужно подтвердить, иначе оно не становится доверенным. Действия по устройству - меню «Действия с устройством», в том числе «Переименовать устройство».

Экран ожидания для самого нового устройства - отдельная страница, пока подтверждение не придёт.

:::note
Новое устройство не откроет хранилище, пока вы не подтвердите его на уже доверенном устройстве.
:::

## Персонализация

Пункт «Персонализация» в группе «Настройки устройства». Эти настройки остаются на этом браузере.

| Настройка | Значения |
| --- | --- |
| «Тема оформления» | «Светлая», «Тёмная», «Системная». |
| «Акцентный цвет» | Палитра акцентов. Подпись кнопки включает идентификатор цвета. |
| «Акцентный оттенок» | «Подкрасить нейтральные цвета». В английской строке: tint neutral surfaces with the selected accent. |

Цвет плитки пространства - другая настройка, она в [основных настройках пространства](./workspace#основное).

## Безопасность

Пункт «Безопасность». Те же локальные prefs, что раньше описывались рядом с мастер-паролем. Они блокируют хранилище, когда вы отходите от компьютера.

| Настройка | Подпись | Значения в коде |
| --- | --- | --- |
| Простой | «Время бездействия на устройстве». «После истечения времени хранилище автоматически заблокируется». | 60, 300, 900, 1800, 3600, 14400 секунд. В интерфейсе это секунды, минуты или «N час». Пока пользователь не задал значение, поле `idleLockSeconds` может отсутствовать. |
| Сон | «Блокировка хранилища при блокировке устройства». «Хранилище автоматически заблокируется если устройство уйдёт в сон или станет неактивным». | По умолчанию включено (`lockOnDeviceSleep: true`). |
| Буфер | «Очищать буфер обмена». «После истечения времени буфер обмена будет автоматически очищен от паролей». | 0 («Никогда», это значение по умолчанию), 10, 30, 60, 120, 300 секунд. Ноль значит буфер сам не чистится. |

## Разблокировка

Пункт «Разблокировка». PIN и биометрия не заменяют мастер-пароль на других устройствах: они живут только здесь.

| Настройка | Подпись | Поведение |
| --- | --- | --- |
| Биометрия | «Биометрическая разблокировка». «Разблокируйте хранилище с помощью биометрии вашего устройства вместо ввода мастер-пароля». | Переключатель, затем «Настроить» / повторная настройка. Если хранилище не открыто, текст просит сначала его разблокировать. Флаг `biometricEnabled` только на этом устройстве. Если платформа биометрию не отдаёт, переключатель недоступен. |
| PIN | «PIN-код». «Разблокируйте хранилище с помощью короткого и безопасного пин-кода на этом устройстве». | 6 цифр (`PIN_LENGTH`). Материал PIN не копируется на другие устройства. |

Экран «Подтвердите доступ» для закрытых зон умеет биометрию, PIN и мастер-пароль - в этом порядке, если они включены. Иначе остаётся мастер-пароль.
