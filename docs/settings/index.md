# Настройки

Настройки разделены на два места, чтобы личное не смешивалось с правилами пространства. Личное и устройство открываются из меню аккаунта. Правила пространства - из сайдбара.

**Личные и устройства** открываются из меню аккаунта: «Мои настройки» и «Настройки устройства». Это попап, не отдельный раздел сайдбара пространства. Пункты попапа:

| Пункт | Куда |
| --- | --- |
| «Основное» | [Личные](./personal#основное) |
| «Мастер пароль» | [Личные](./personal#мастер-пароль) |
| «Методы входа» | В коде есть, в интерфейсе скрыт. См. [личные](./personal#методы-входа). |
| «2ФА аутентификация» | [Личные](./personal#двухфакторная-аутентификация) |
| «Восстановление» | [Личные](./personal#восстановление) |
| «Мои устройства» | [Устройства](./devices#мои-устройства) |
| Группа «Настройки устройства»: «Персонализация», «Безопасность», «Разблокировка» | [Устройства](./devices) |

**Пространство** - пункт сайдбара «Настройки». Разделы:

| Раздел | Страница |
| --- | --- |
| «Основное», внутри него «Записи» и «Капсулы» | [Пространство](./workspace#основное) |
| «Роли» | [Пространство](./workspace#роли) |
| «Профили» | [Пространство](./workspace#профили) |
| «Участники» | [Пространство](./workspace#участники) |
| «Сейфы» | [Пространство](./workspace#сейфы) |

Кто видит раздел настроек пространства, задаёт роль. Встроенные роли: «Владелец», «Админ», «Пользователь». У «Пользователя» подпись «Без доступа к настройкам пространства».
