# Экспорт

Экспорт собирает файл у вас в браузере, из уже открытого хранилища. Текст раздела: «Экспортируйте свои данные в файл для резервного копирования или переноса в другой сервис.»

Экспорт есть на тарифе «Бесплатный» и на тарифе «Предприятие». В файл попадают записи выбранного сейфа, которые вам видны. Удалённые записи не входят.

## Как экспортировать

1. «Выберите сейф для экспорта записей». Поиск: «Поиск сейфа». Без права экспорта из этого сейфа: «Нет доступа для экспорта из выбранного сейфа».
2. «Формат». Поиск: «Поиск формата».
3. «Включить папки» видно только у форматов, которые пишут пути папок. Подпись: «Пути папок будут записаны в экспорт, чтобы их можно было восстановить при импорте.»
4. «Защитить паролем» видно только у форматов, где в таблице колонка «Пароль» отмечена «да». Поле «Пароль экспорта». Подпись: «Зашифровать файл экспорта. Пароль понадобится при импорте.» Пока пароль пустой, кнопка не нажимается.
5. Перед кнопкой текст, сколько записей уйдёт в файл: «N записей будет экспортировано». Кнопка «Экспортировать». Ход: «Подготовка записей…», «Подготовка N/M: название», «Сборка файла экспорта…». Успех: «Экспортировано записей: N → файл». Ошибка: «Не удалось выполнить экспорт».

Имя файла начинается с `okkey-export-` и даты, расширение берётся из формата.

:::warning
Запомните пароль экспорта отдельно от мастер-пароля. Им открывается зашифрованный файл при импорте.
:::

Yandex Browser (zip) можно только импортировать. В списке экспорта его нет. Названия ZIP Okkey и Bitwarden в интерфейсе содержат «с файлами» и на английском языке тоже.

## Как проверить

1. Откройте «Экспорт» на тарифе «Бесплатный» и выберите личный сейф с парой записей.
2. Формат Okkey (csv): переключателя «Защитить паролем» нет, «Включить папки» есть. Кнопка «Экспортировать» скачивает файл, тост называет число записей и имя файла.
3. Формат Okkey (json): появляется «Защитить паролем». С пустым паролем кнопка не нажимается. С паролем файл скачивается, а [импорт](./import.md) этого файла спрашивает «Пароль экспорта».
4. В списке нет «Yandex Browser (zip)».
