# Генератор

Три вкладки: «Пароль», «Кодовая фраза», «Имя пользователя». Они одинаково работают в вебе и в расширении. Подробности окна расширения в [браузерном расширении](../apps/extension.md).

Пароль собирается в браузере. Настройки генератора запоминаются в этом браузере и в сейф не записываются. Генератор есть на тарифе «Бесплатный» и на тарифе «Предприятие».

Кнопка обновления подписана для программ чтения «Сгенерировать заново». Копирование: подсказка «Скопировать», для программ чтения «Скопировать сгенерированное значение».

## Пароль {#пароль}

Длина 4–128, по умолчанию 16. Подпись ползунка: «Символов: N». Наборы по умолчанию: «A-Z» включены, «a-z» включены, «0-9» включены, «!@#$%^&*» выключены. Если снять все четыре набора, «a-z» остаётся включённым.

Рядом «Надёжность:» и «Время взлома:». Надёжность: «Слабый», «Средний», «Хороший», «Сильный», «Отличный». Время взлома: «Мгновенно», «Часы», «Дни», «Месяцы», «Годы», «Десятилетия», «Века», «Никогда». Это оценка по энтропии, не обещание срока подбора.

Тот же генератор открывается из записи: у поля пароля «Генератор», затем «Вставить» или «Отмена». В карточке записи кнопка обновления подписана «Сгенерировать снова».

## Кодовая фраза {#кодовая-фраза}

Слова из списка EFF large. По умолчанию 3 слова, разделитель `-`, без заглавных и без цифры. Диапазон слов: 3–20. Подпись ползунка: «Слов: N».

«С заглавной буквы» поднимает первую букву каждого слова. «Включить цифру» дописывает одну цифру 0–9 к случайному слову. «Разделитель» это один символ. Если ввести больше, берётся первый. Пустой заменяется на `-`.

## Имя пользователя {#имя-пользователя}

Одно слово из того же списка. «С заглавной буквы». «Включить число» дописывает 4 цифры от 0000 до 9999. По умолчанию оба выключателя сняты.

## Как проверить

1. Откройте «Инструменты», «Генератор». Активна вкладка «Пароль», длина 16, символы выключены.
2. Снимите «a-z», «A-Z» и «0-9». «a-z» включается снова, пустой пароль не остаётся.
3. На «Кодовая фраза» поставьте 3 слова и разделитель длиннее одного символа. В значении остаётся первый символ.
4. Закройте вкладку и откройте генератор снова. Длина и наборы те же, в сейф новая запись не попала.
