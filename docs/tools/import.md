# Импорт

Импорт переносит записи из файла в выбранный сейф. Текст раздела: «Перенесите данные из других сервисов в Okkey за несколько шагов. Поддерживаются стандартные форматы и импорт из популярных менеджеров паролей.»

Импорт есть на тарифе «Бесплатный» и на тарифе «Предприятие».

## Как импортировать

1. «Выберите сейф для импорта записей». Нет права писать в этот сейф: «Нет доступа для записи в выбранный сейф».
2. «Формат». Поиск: «Поиск формата». Пустой поиск: «Формат не найден».
3. Способ ввода: «Файл» или «Текст». «Загрузить файл», «Удалить файл». Для текста поле подписано «Текст», подсказка «Вставьте содержимое экспорта». «Текст» пропадает у форматов, которым нужна только загрузка файла. Сам файл импорта не больше 200 МБ.
4. «Импортировать папки» видно только у форматов, которые умеют папки. Переключатель создаёт дерево папок и раскладывает записи по ним. Папки личные, см. [Папки](../items/folders.md).
5. «Импортировать». Ход: «Разбор файла…», затем «Импорт N/M: название». Успех: «Импортировано записей: N. Пропущено: M.» Часть записей могла не попасть: «Часть записей не импортирована (N).» Пустой разбор: «Не найдено записей для импорта».

Если файл Okkey (json), Okkey ZIP, Bitwarden (json) или Bitwarden ZIP закрыт паролем экспорта, открывается окно «Пароль экспорта». Кнопка «Разблокировать». Неверный пароль: «Неверный пароль экспорта». У остальных форматов это окно не открывается.

Для Okkey ZIP и Bitwarden ZIP с вложениями есть примечание. Архив может быть большим, каждое вложение ограничено размером из настроек пространства, и загружаются только форматы, разрешённые в настройках.

:::note
Файлы из ZIP попадут в записи, только если включено «Разрешить файлы в записях». На self-hosted настройка есть на тарифе «Бесплатный» и на тарифе «Предприятие».
:::

Незнакомый идентификатор формата при разборе читается как Custom CSV. В списке на экране выбирается один из форматов ниже.

## Как проверить

1. Откройте «Импорт» на тарифе «Бесплатный». Список «Формат» содержит строки таблицы, включая «1Password (csv)» и «1Password (1pux)».
2. Выберите Chrome (csv). Вкладок две: «Файл» и «Текст». Переключателя «Импортировать папки» нет.
3. Выберите Okkey ZIP (с файлами). Остаётся только «Файл», папки есть, под полем примечание про вложения.
4. Импортируйте короткий csv в личный сейф. Тост: «Импортировано записей: N. Пропущено: M.» Записи появляются в выбранном сейфе.
