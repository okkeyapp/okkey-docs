# Сейфы

Сейф - контейнер записей со своим ключом. Записи шифруются этим ключом, поэтому доступ к сейфу и есть доступ к записям. Участник видит только те сейфы, которые разрешает его профиль.

Секция сайдбара «Сейфы». Кнопка в сайдбаре: «Создать сейф».

## Личный сейф

В каждом пространстве один личный сейф. Он создаётся вместе с пространством. В настройках он называется «Личный сейф», подпись «Доступен только Вам». На Free других сейфов нет: флаг `sharedVaults` выключен.

Записи, папки и избранное внутри личного сейфа принадлежат вам. Папки при этом всё равно личные и не становятся общими, даже если запись лежит в общем сейфе: папку видит только её владелец. См. [Папки](./folders).

Имя личного сейфа по умолчанию задаётся при создании. Попап «Редактировать сейф» подключает `workspace-shared-vaults`: «Иконка», «Название», «Описание» и заметка, что сейф видит только владелец. Второго личного сейфа этот попап не создаёт. Поля и запрет выдать доступ - в [настройках сейфов](./settings/workspace#сейфы).

## Общие сейфы

На Enterprise (`sharedVaults` включён, модули загружены при `ENTERPRISE_MODULES=true`) можно создавать сейфы для участников. В настройках секция «Общие сейфы», подпись «Сейфы с общим доступом для участников пространства», кнопка «Создать».

Создание, удаление и выдача доступа - плагин `workspace-shared-vaults`. Ядро хранит список, чтение и ключ `GET …/key`, а wrap и rotate делает `VaultSharingService`. Получатель не может открыть сейф, пока ему не завернули ключ его публичным ключом (гибридный конверт v2). Попап: иконка, название, описание и селект профиля у каждого участника. При создании владелец, админ и создатель получают «Расширенный». Остальные - «Без доступа». Подробности попапа - в [настройках сейфов](./settings/workspace#сейфы).

Что видит участник внутри общего сейфа, решает профиль: категории, поля, функции «Помещать в архив», «Добавлять в избранное», «Создавать капсулы», «Копировать запись». Роль на это не влияет.

В мониторинге область «Общие» считает пароли только этих сейфов. В списке записей фильтр «Сейфы» выбирает один сейф.

:::note
На Free секции «Общие сейфы» нет. Чтобы они появились у нового пространства, при установке нужно `ENTERPRISE_MODULES=true`.
:::

## Сайдбар

«Все записи» сбрасывает сейф, папку, поиск и фильтр списка. Сейф в сайдбаре сужает список до своих записей. Пока имя сейфа грузится, в фильтре может кратко мелькнуть идентификатор.
