# Folders

Folders group your items. The items stay in the vault. Only you see a folder, on Free and on Enterprise.

Sidebar section "Folders". If there are no folders, the section shows "No folders". One "Folder settings" button opens the "Folders" window.

## Create and edit

In the "Folders" window: "Add folder", "Edit folder", "Delete folder", "Save", "Cancel". Order and nesting are changed here too. Nesting is unlimited. Deleting a folder leaves the items in the vault.

The same window opens from the web sidebar and from the extension.

## How a folder relates to items

An item has one folder in the vault where it lives. The "Folders" filter keeps items in the selected folder and in nested folders, in the web app and in the extension. A text search drops the folder and the vault. See [Lists](./lists).

Import with "Import folders" creates the tree and places the items. Export with "Include folders" writes paths when the format supports them.
