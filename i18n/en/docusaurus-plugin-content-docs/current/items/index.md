# Items

An item is a login, a card, a note, or another secret inside a vault. "All items" in the sidebar and the "Add records" button open the category catalog. An item lives in a vault, may live in a folder, and has a category, sections, and fields.

## Where to look

1. [Categories and templates](./categories) - what you can create and the order it is shown in.
2. [Fields and sections](./fields) - types, the field gear menu, hidden modes.
3. [Item actions](./actions) - row and card menus.
4. [Lists](../lists) - search, filters, sort.
