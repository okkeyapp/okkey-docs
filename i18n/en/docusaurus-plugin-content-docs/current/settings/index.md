# Settings

The interface has two different places.

**Personal settings and devices** open from the account menu: “My settings” and “Device settings”. This is a popup, not a workspace sidebar section. Popup items:

| Item | Where |
| --- | --- |
| “General” | [Personal](./personal#general) |
| “Master password” | [Personal](./personal#master-password) |
| “Sign-in methods” | Present in code, hidden in the UI. See [personal](./personal#sign-in-methods). |
| “2FA authentication” | [Personal](./personal#two-factor-authentication) |
| “Recovery” | [Personal](./personal#recovery) |
| “My devices” | [Devices](./devices#my-devices) |
| Group “Device settings”: “Personalization”, “Security”, “Unlock” | [Devices](./devices) |

**Workspace** is the sidebar item “Settings”. Sections:

| Section | Page |
| --- | --- |
| “General”, with “Items” and “Capsules” nested under it | [Workspace](./workspace#general) |
| “Roles” | [Workspace](./workspace#roles) |
| “Profiles” | [Workspace](./workspace#profiles) |
| “Members” | [Workspace](./workspace#members) |
| “Vaults” | [Workspace](./workspace#vaults) |

Who can see a workspace settings section is decided by the role. Built-in roles: “Owner”, “Admin”, “User”. The user role’s description is “No access to workspace settings”.
