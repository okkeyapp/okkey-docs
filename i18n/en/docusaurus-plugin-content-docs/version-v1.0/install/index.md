# Self-hosted install

Self-hosted puts Okkey on your machine. Encryption stays on your device, so vault contents cannot be read from the server.

An install you do yourself runs on Free. An Okkey employee sets up Enterprise. What each plan includes is on [Plans](../plans.md).

Only Docker Compose is supported. Kubernetes and Helm are planned and are not part of v1.0.0.

## Where to start

1. Check the [requirements](./requirements.md): Docker and disk for the data.
2. Install Okkey using the [install steps](./free.md).
3. Create the first account in [first-time setup](../getting-started/first-setup.md).
