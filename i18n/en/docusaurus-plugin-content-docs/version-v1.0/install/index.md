# Self-hosted install

Self-hosting runs Okkey on your machine. Encryption stays on the client, so the server administrator cannot read your vaults.

A new workspace is Free when `ENTERPRISE_MODULES=false` or the variable is unset. It is Enterprise when `ENTERPRISE_MODULES=true`. What each plan includes is on [Plans](../plans).

## Where to start

1. Check the [requirements](./requirements): Docker Compose and access to the images.
2. Install Okkey with the [install steps](./self-hosted).
3. Create the first account in [first-time setup](./first-setup).

:::tip
Pick the plan before registration. Later, Free moves to Enterprise only when you ask an Okkey specialist.
:::
