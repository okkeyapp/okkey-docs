# Plans

Self-hosted Okkey has two plans: Free and Enterprise. You install Okkey yourself, and that install runs on Free. An Okkey employee turns on Enterprise. To get Enterprise, write to the Okkey team from [Change plan](./workspace/plan.md).

On self-hosted, an owner has one workspace. That is true on Free and on Enterprise.

## What's included

The numbers below come from the self-hosted plan matrix. The personal vault does not count toward the shared-vault limit. The owner does not count toward the member limit.

| Capability | Free | Enterprise |
| --- | --- | --- |
| Capsules, including a file | yes | yes |
| Files in items | yes | yes |
| Capsule view limit from workspace settings | yes | yes |
| Advanced capsule settings: expiry, a password and attempt count, members only, owner approval | no | yes |
| Built-in roles ("Owner", "Admin", "User") and profiles ("Simple", "Extended") | yes | yes |
| Custom roles and profiles | no | yes |
| Recovery key | yes | yes |
| Trusted devices and trusted contacts | no | yes |
| Shared vaults | 1 | no limit |
| Additional members | 10 | no limit |
| Generator, import, and export | yes | yes |
| Monitoring | no | yes |
| Storage ceiling | no | no |

The Enterprise card in Change plan also lists "Unlimited storage" and "Priority support". Self-hosted already has no storage ceiling on Free. Use the table above for what each plan includes.

## When the Enterprise license ends

Nothing is moved to Free. Your data stays available. Enterprise features stop receiving updates. You cannot create new objects in those features or change existing ones. You can still delete.

## How to check

1. On Free the sidebar has no "Monitoring". In Settings, Vaults you can create one shared vault. A second one is not saved.
2. In Members an invite goes through while additional members and live invites stay within 10.
3. Roles and Profiles show the built-in rows. The custom roles and profiles block says the feature is not available on the current plan.
4. In My settings, Recovery there is "Recovery key". "Trusted devices" and "Trusted contacts" cannot be turned on on Free.
