# Plans

Self-hosted Okkey has two plans: Free and Enterprise. Files in items and Monitoring are on both. The plan decides whether you can invite people, share vaults, and turn on advanced recovery.

You install Okkey yourself. That install runs on Free.

An Okkey employee sets up Enterprise. To get Enterprise, contact the Okkey team.

When your Enterprise license expires, a soft lock turns on. Everything you've already created stays available. Until you renew, you can't create anything new or change what exists in Enterprise features, only delete it, and Enterprise updates stop.

On self-hosted, an owner has one workspace.

## What's included

| Capability | Free | Enterprise |
| --- | --- | --- |
| Capsules | yes | yes |
| Advanced settings | no | yes |
| Allow files in items | yes | yes |
| Monitoring | yes | yes |
| Recovery key | yes | yes |
| Trusted devices | no | yes |
| Trusted contacts | no | yes |
| Shared vaults | no | yes |
| Additional members | no | yes |
| Built-in roles ("Owner", "Admin", "User") | yes | yes |
| Custom roles | no | yes |
| Built-in profiles ("Simple", "Extended") | yes | yes |
| Custom profiles | no | yes |
