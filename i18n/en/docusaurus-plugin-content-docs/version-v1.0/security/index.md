# Features

The four properties below explain why the server cannot read your items.

- [Q-Day ready](./qday.md) - hybrid encryption of new items, with a post-quantum part.
- [Protection](./keys.md) - a key from three shares, and a separate key for each vault.
- [Zero-knowledge](./zero-knowledge.md) - the server stores ciphertext, and open secrets stay with you.
- [Open source, including encryption](./open-source.md) - the encryption is published with Okkey.
