# Tools

The sidebar item "Tools" creates a password or moves items without leaving the vault. The menu has three sections: "Generator", "Import", "Export".

The generator, import, and export are available on Free and on Enterprise. Files inside a ZIP are saved when "Allow files in items" is on. On self-hosted that setting is available on Free too. How to turn it on is in [item settings](../workspace/index.md#items).

## How to check

1. Open "Tools". The menu has three items, and none of them says "This tool is coming soon."
2. On Free the generator shows a password immediately, and import and export open without a plan note.
