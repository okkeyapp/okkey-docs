# Tools

The sidebar item "Tools" creates a password or moves items without leaving the vault. The menu has three sections: "Generator", "Import", "Export".

The generator, import, and export are available on Free. Files inside a ZIP are saved when "Allow files in items" is on. That setting is available on Free too. How to turn it on is in [item settings](../workspace/index.md#items).
