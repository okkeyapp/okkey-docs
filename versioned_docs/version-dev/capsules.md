# Капсулы

Пункт сайдбара «Капсулы». Текст списка: «Капсулы — это специальные зашифрованные записи для безопасной передачи по электронной почте или в чате.»

Капсула есть на Free и на Enterprise. На Free это ссылка без настроек доступа: флаг `capsuleAccessSettings` выключен. На Enterprise блок «Расширенные настройки» включён. Пока блок закрыт, интерфейс пишет: «Расширенные настройки доступны в тарифе Enterprise.» Рядом у каждой выключенной строки: «Недоступно на текущем тарифе».

Политики пространства могут обязать часть этих настроек. Их задают в [настройках капсул](./settings/workspace#капсулы). Если участнику запрещено создавать капсулы, пункт для него не работает.

## Список

Пустой список: «Капсулы ещё не созданы». Кнопка «Создать капсулу». Поиск: «Поиск по названию...». Если ничего не нашёл: «По Вашему запросу "…" результаты не найдены».

Колонки («Колонки»): «Название», «Тип», «Создан», «Изменён», «Активен», «Просмотров», «С паролем».

Тип: «Текст», «Файл», «Запись». Пароль в колонке: «Да» или «Нет». Даты относительно сегодня: «Сегодня», «Вчера». Активность: «С …», «До …».

Строку можно выделить. Счётчик — число капсул. Массовые действия из тостов: деактивировать («Капсула деактивирована»), активировать, удалить, скопировать ссылку («Ссылка скопирована»). Создание с копированием ссылки: «Капсула создана, ссылка скопирована».

Удаление спрашивает «Удалить капсулу?» или «Удалить капсулы?». Текст: капсула удаляется без восстановления, ссылка перестаёт работать. Это не корзина записей.

## Новая капсула

Окно «Новая капсула» или «Редактирование капсулы». Поле «Название».

Содержимое:

- текст — «Введите текст, которым хотите поделиться»;
- файл — «Загрузить файл» / «Удалить файл», с лимитами файлов пространства;
- запись — «Поиск записи», «Введите текст для поиска». Поиск ищет по незашифрованным полям пресетных секций, не по секретам. Пусто: «Записей не найдено». Область полей записи: «Все», «Все кроме», «Выбранные», подпись «Доступные поля:».

Кнопка «Расширенные настройки» показывает, сколько блоков включено.

| Блок | Заголовок | Что задаётся |
| --- | --- | --- |
| Просмотры | «Просмотры». «Ограничьте просмотры и назначьте действие после достижения ограничения». | «Количество просмотров:». «Дальнейшее действие:» — «Деактивировать» или «Удалить капсулу». |
| Время | «Время». «Активируйте, деактивируйте и удаляйте капсулу по времени». | «Активировать:», «Деактивация по времени:», «Удаление по времени:». Пресеты: «Никогда», «Сразу», «Через 15 минут», «Через 1 час», «Через 6 часов», «Через 12 часов», «Через 24 часа», «После активации», либо дата и время («Час», «Мин», «Сегодня», «Готово»). Деактивация раньше активации: «Время деактивации не может быть раньше времени активации». Удаление раньше активации — такая же ошибка. |
| Доступ | «Доступ». «Разрешите просмотр только конкретным пользователям». | «Выберите пользователей», поиск «Имя, фамилия или email…». Чужой email можно добавить («Добавить …»), неверный адрес: «Неверный емейл». |
| Пароль | «Пароль». «Требовать ввести пароль для просмотра». | «Задайте пароль:». При редактировании пустое поле — «Оставьте пустым, чтобы не менять». «Колличество неудачных попыток:» — так подписано в строке, с этой орфографией. |
| Подтверждение | «Подтверждение». «Требовать подтверждение владельца перед показом». | Владелец видит «Подтвердите показ капсулы». Текст: «… хочет просмотреть капсулу «…».» Поля заявки: «Устройство», «Система», «Страна», «Город», «Время». Кнопки: «Одобрить», «Запретить показ». «Другие действия запрета» → «Добавить в чёрный список» («Этот емейл или IP больше не сможет подать заявку на показ этой капсулы»). Гость без имени — «Гость» или «Неизвестный пользователь». |

«Установить эти настройки по умолчанию для меня» запоминает расширенные настройки для следующих капсул этого пользователя.

Если политика пространства уже включила блок, его нельзя выключить в карточке.

## Ссылка для получателя

Публичная страница капсулы открывается без входа в хранилище. Получатель видит только то, что разрешила карточка: пароль, ожидание одобрения, лимит просмотров или срок. Геолокация заявки, если GeoIP на сервере включён, считается локально по MMDB. В self-host compose по умолчанию GeoIP выключен, тогда страна и город могут остаться «Неизвестно».

Шифрование содержимого капсулы — клиентский XChaCha20-Poly1305, как у других конвертов ядра. Сервер хранит шифротекст и правила доступа, не открытый текст.
