# Папки

Секция сайдбара «Папки». Пусто: «Нет папок». Кнопки: «Создать папку» и «Настройки папок».

Окно «Папки» объясняет правило целиком: «Папки помогают структурировать записи. Создавайте любое количество папок, упорядочивайте их и выстраивайте неограниченную вложенность. Изменения в структуре папок не затрагивают сами записи. Ваши папки можете видеть только Вы.»

Папки есть на всех тарифах. Это не сейф и не общий каталог пространства.

## Создание и правка

В окне: «Добавить папку», «Редактировать папку», «Удалить папку», «Сохранить», «Отмена». Вложенность не ограничена кодом этого текста. Удаление папки не удаляет записи: они остаются в сейфе, просто без этой папки.

Порядок папок меняется в том же окне. В расширении пункты создания папки и настроек папок в меню спрятаны: папки видны, управлять ими нужно в вебе.

## Как папка связана с записями

У записи одна папка в сейфе, где она лежит. Фильтр списка «Папки» показывает дерево и оставляет записи выбранной ветки. Поиск по тексту папку и сейф сбрасывает и ищет по всем записям, см. [Списки](./lists).

Импорт с «Импортировать папки» создаёт дерево под выбранной папкой и раскладывает записи. Экспорт с «Включить папки» пишет пути, если формат их умеет.

В расширении у карточки есть назначение папки, но настройки дерева — в вебе.
