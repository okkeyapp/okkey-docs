# Тарифы

У self-hosted два тарифа. От этого зависит, что вы можете делать в пространстве: приглашать людей, делиться сейфами, включать расширенное восстановление.

Новое пространство получает тариф в момент регистрации. Уже созданное пространство Free переводится на Enterprise отдельно, по запросу.

## Как выбирается тариф

Переключатель модулей - это переменная окружения. Дальше в документации она пишется только так:

- `ENTERPRISE_MODULES=false`, или переменная не задана. Новое пространство получает Free (`plan_tier` `FREE`).
- `ENTERPRISE_MODULES=true`. Новое пространство получает Enterprise (`plan_tier` `ENTERPRISE`), и подключаются плагины enterprise.

Незнакомая строка `plan_tier` тоже становится `FREE`.

Как задать переменную при установке, смотрите в [установке](./install/self-hosted#модули-enterprise).

В self-hosted у владельца одно пространство.

## Уже созданное пространство

:::note
Если пространство уже создано как Free, перевести его на Enterprise может только специалист Okkey, и только по вашему запросу. Напишите команде Okkey и дайте SSH-доступ к VPS, где установлен Okkey.
:::

## Что входит

| Возможность | Free | Enterprise |
| --- | --- | --- |
| Капсулы | да | да |
| Расширенные настройки | нет | да |
| Разрешить файлы в записях | да | да |
| Мониторинг | да | да |
| Ключ восстановления | да | да |
| Доверенные устройства | нет | да |
| Доверенные контакты | нет | да |
| Общие сейфы | нет | да |
| Дополнительные участники | нет | да |
| Встроенные роли («Владелец», «Админ», «Пользователь») | да | да |
| Пользовательские роли | нет | да |
| Встроенные профили («Простой», «Расширенный») | да | да |
| Пользовательские профили | нет | да |
