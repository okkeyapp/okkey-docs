# Инструменты

Пункт сайдбара «Инструменты». Внутри три раздела: «Генератор», «Импорт», «Экспорт». Других инструментов в меню нет. Заглушка «Этот инструмент скоро появится.» в строках есть. **TODO:** к какому пункту она привязана в текущем меню, отдельно от трёх разделов не видно — в сайдбаре инструментов только эти три.

Генератор, импорт и экспорт доступны на Free. Файлы внутри ZIP упираются в [настройку файлов](./settings/workspace#записи) и на Free не сохраняются, если файлы в записях выключены.

## Генератор

«Быстрый и удобный генератор поможет вам создать сложные пароли для обеспечения безопасности вашей информации.» Переключатель «Тип генератора»: «Пароль», «Кодовая фраза», «Имя пользователя». Кнопки «Сгенерировать заново» и «Скопировать сгенерированное значение».

### Пароль

Длина 4–128, по умолчанию 16. Наборы по умолчанию: A-Z включены, a-z включены, 0-9 включены, символы `!@#$%^&*` выключены. Подписи в карточке записи те же: «A-Z», «a-z», «0-9», «!@#$%^&*», «Символов: N». Рядом «Надёжность:» и «Время взлома:». Время — оценка по энтропии. Подписи шкалы: «Мгновенно», «Часы», «Дни», «Месяцы», «Годы», «Десятилетия», «Века», «Никогда». Это не обещание реальной стойкости, а подпись шкалы.

Тот же генератор открывается шестерёнкой у поля пароля в записи: «Генератор», затем «Вставить» или «Отмена».

Случайность — `crypto.getRandomValues`.

### Кодовая фраза

Слова из списка EFF large. По умолчанию 3 слова, разделитель `-`, без заглавных и без цифры. Диапазон слов: 3–20. «С заглавной буквы» поднимает первую букву каждого слова. «Включить цифру» дописывает одну цифру 0–9 к случайному слову. «Разделитель» — один символ; если ввести больше, берётся первый, пустой заменяется на `-`.

### Имя пользователя

Одно слово из того же списка. «С заглавной буквы». «Включить число» дописывает 4 цифры от 0000 до 9999. По умолчанию оба выключателя сняты.

Настройки генератора запоминаются в `localStorage` браузера, не в сейфе.

## Импорт

«Перенесите данные из других сервисов в Okkey за несколько шагов. Поддерживаются стандартные форматы и импорт из популярных менеджеров паролей.»

Поля:

- «Выберите сейф для импорта записей» — запись пойдёт в выбранный сейф. Нет права писать: «Нет доступа для записи в выбранный сейф».
- «Формат», поиск «Поиск формата», пусто: «Формат не найден».
- Способ ввода: «Файл» или «Текст». «Загрузить файл», «Удалить файл», для текста — «Вставьте содержимое экспорта».
- «Импортировать папки». «При импорте будут созданы все папки и подпапки внутри выбранной папки выше, а записи сразу попадут в соответствующие папки.» Папки личные, см. [Папки](./folders).

Если файл закрыт паролем экспорта: окно «Пароль экспорта», «Разблокировать». Неверный пароль: «Неверный пароль экспорта».

Ход: «Разбор файла…», затем «Импорт N/M: название». Успех: «Импортировано записей: N. Пропущено: M.» Часть записей могла не попасть: «Часть записей не импортирована (N).» Пустой разбор: «Не найдено записей для импорта».

Для ZIP с вложениями примечание: архив может быть большим, каждое вложение ограничено настройкой пространства в мегабайтах, и «Загрузятся только форматы, разрешённые в настройках».

## Экспорт

«Экспортируйте свои данные в файл для резервного копирования или переноса в другой сервис.»

- «Выберите сейф для экспорта записей». Нет права: «Нет доступа для экспорта из выбранного сейфа».
- «Формат».
- «Включить папки» — «Пути папок будут записаны в экспорт, чтобы их можно было восстановить при импорте.» Не у всех форматов пути папок поддерживаются (см. таблицу).
- «Защитить паролем» — «Зашифровать файл экспорта. Пароль понадобится при импорте.» Поле «Пароль экспорта». Флаг есть только у форматов, у которых `supportsExportPassword`.

Перед кнопкой текст, сколько записей уйдёт в файл. Ход: «Подготовка записей…», «Сборка файла экспорта…». Успех: «Экспортировано записей: N → файл». Ошибка: «Не удалось выполнить экспорт».

Yandex Browser (zip) есть только в импорте. В `exportFormatOptions` этого формата нет. Имена форматов зашиты в коде и не переводятся: ZIP Okkey и Bitwarden подписаны «с файлами» и в английском интерфейсе.

Экспорт идёт из открытого хранилища на клиенте: файл собирается в браузере. Пароль экспорта — отдельный пароль файла, не мастер-пароль.
