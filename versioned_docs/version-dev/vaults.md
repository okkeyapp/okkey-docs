# Сейфы

Секция сайдбара «Сейфы». Сейф — контейнер записей со своим ключом. Записи шифруются ключом сейфа. Участник видит только те сейфы, к которым у него есть доступ профиля.

Кнопка в сайдбаре: «Создать сейф».

## Личный сейф

В каждом пространстве один личный сейф. Он создаётся вместе с пространством. В настройках он называется «Личный сейф», подпись «Доступен только Вам». На Free и Pro других сейфов нет: флаг `sharedVaults` выключен, квота общих сейфов 0.

Записи, папки и избранное внутри личного сейфа принадлежат вам. Папки при этом всё равно личные и не становятся общими, даже если запись лежит в общем сейфе: папку видит только её владелец. См. [Папки](./folders).

Имя личного сейфа по умолчанию задаётся при создании. Попап смены метаданных в открытой сборке не подключён. **TODO:** поля попапа личного сейфа (иконка, имя) описаны только как плагин `workspace-shared-vaults`.

## Общие сейфы

С Family (и на self-hosted enterprise, если лицензия включает общие сейфы) можно создавать сейфы для участников. В настройках секция «Общие сейфы», подпись «Сейфы с общим доступом для участников пространства», кнопка «Создать».

Лимиты каталога: Family — 5, Team — 50, Enterprise — без лимита.

Создание, удаление и выдача доступа — плагин. Ядро хранит список, чтение и ключ `GET …/key`, а wrap и rotate делает `VaultSharingService`. Получатель не может открыть сейф, пока ему не завернули ключ его публичным ключом (гибридный конверт v2).

Что видит участник внутри общего сейфа, решает профиль: категории, поля, функции «Помещать в архив», «Добавлять в избранное», «Создавать капсулы», «Копировать запись». Роль на это не влияет.

В мониторинге область «Общие» считает пароли только этих сейфов. В списке записей фильтр «Сейфы» выбирает один сейф.

## Сайдбар

«Все записи» сбрасывает сейф, папку, поиск и фильтр списка. Сейф в сайдбаре сужает список до своих записей. Пока имя сейфа грузится, в фильтре может кратко мелькнуть идентификатор.
