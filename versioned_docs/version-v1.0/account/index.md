# Аккаунт и устройства

Личные настройки открываются из меню аккаунта: «Мои настройки». Это окно со своим адресом `?popup=settings`. Язык интерфейса переключается и в шапке веба. Правила пространства открываются из пункта сайдбара «Настройки».

Пункт «Методы входа» в меню не показывается. Вход идёт по email и коду из письма. Дополнительно можно включить [двухфакторную аутентификацию](./two-factor.md).

Группа «Настройки устройства» («Персонализация», «Безопасность», «Разблокировка») действует только в этом браузере и на другие устройства не переносится.
