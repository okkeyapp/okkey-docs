# Браузерное расширение

Расширение подставляет логин и пароль на сайте, пока хранилище разблокировано. Оно называется «Okkey» и работает в Chromium (Chrome, Edge, Opera, Yandex) и в Firefox.

В Chrome Web Store и Firefox Add-ons расширения пока нет.

## Вход

1. В окне расширения укажите адрес вашего Okkey.
2. Вход открывает веб и возвращает сессию в расширение.
3. Новое устройство ждёт подтверждения на уже доверенном устройстве.
4. «Разблокировать» запрашивает тот же мастер-пароль, что и веб.

«Выйти» и «Сменить сервер» стирают сессию расширения и оставляют только последний адрес сервера.

## Окно расширения

После разблокировки доступны поиск, блокировка и создание записи. Запись создаётся в вебе.

В меню: переключатель пространства, сейфы, папки и выход. Создать сейф и настроить дерево папок можно в вебе.

Правка записи, капсула, избранное и архив тоже открывают веб.

## Автозаполнение

На странице расширение подставляет логин, пароль и одноразовый код для категории «Логин / пароль». У поля «URL сайта» три режима:

- «Заполнять на всём сайте»
- «Заполнять только на этом URL»
- «Без автозаполнения»

Если хранилище закрыто, на странице есть «Разблокировать». Копирование логина или пароля на сайте, которого нет среди адресов записи, спрашивает подтверждение.

Генератор пароля прямо на странице сайта пока недоступен. Генератор в вебе описан в [Инструментах](../tools).
