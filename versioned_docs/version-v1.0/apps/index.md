# Приложения и расширения

В архитектуре ядра перечислены веб, мобильное приложение (React Native), десктоп (Tauri) и браузерное расширение. Веб ставится вместе с self-hosted. Остальные клиенты в репозитории есть, но готовой установки для пользователя у них пока нет.

:::note
В дереве `dev` каталоги `apps/mobile` и `apps/desktop` есть. Пользовательской установки из магазина или готового пакета в открытых README нет. **TODO:** как ставить мобильное и десктопное приложение конечному пользователю, в коде не описано.
:::
