# Капсулы

Капсула передаёт текст, файл или запись по ссылке. Содержимое шифруется на вашем устройстве. На странице получателя написано: «Данные расшифровываются только на устройстве, сервер их не видит». Сервер хранит шифротекст и правила доступа.

Пункт сайдбара «Капсулы». Текст списка говорит, что капсулы это специальные зашифрованные записи для безопасной передачи по электронной почте или в чате.

Капсула есть на Free и на Enterprise. На self-hosted файл в капсуле тоже есть на Free. Расширенные настройки доступа (срок, список получателей, пароль, подтверждение владельца и свой лимит просмотров) есть на Enterprise. Лимит просмотров, заданный в настройках пространства, действует и на Free.

Политики пространства задают в [настройках капсул](./workspace/index.md#капсулы). Если участнику запрещено создавать капсулы, создание для него закрыто.

## Список

Кнопка «Создать капсулу». Поиск: «Поиск по названию...». Пустой список: «Капсулы ещё не созданы».

Колонки: «Название», «Тип», «Создан», «Изменён», «Активен», «Просмотров», «С паролем». Тип: «Текст», «Файл», «Запись». В «Активен» и «С паролем» значения «Да» и «Нет».

Строку можно выделить. В меню: «Деактивировать», «Активировать», «Удалить», «Копировать ссылку». После создания тост: «Капсула создана, ссылка скопирована».

Удаление спрашивает «Удалить капсулу?». Текст: «Капсула будет удалена без возможности восстановления. Ссылка перестанет работать.» Кнопка «Удалить». Капсула не попадает в корзину записей.

## Новая капсула

Окно «Новая капсула» или «Редактирование капсулы». Поле «Название».

Содержимое:

- «Текст». Поле «Секретный текст», подсказка «Введите текст, которым хотите поделиться».
- «Файл». «Загрузить файл» и «Удалить файл». На self-hosted тип доступен на Free. Размер и расширения те же, что в [настройках записей](./workspace/index.md#записи). Если тип выключен политикой, карточка пишет: «Этот тип капсул отключён в настройках пространства. Можно только удалить капсулу.»
- «Запись». «Поиск записи», подсказка «Введите текст для поиска». Обычный запрос ищет по названию, по описанию, которое видно в списке, и по URL. Метки находятся только запросом вида `#метка` и только при полном совпадении, без учёта регистра. Открытые поля основной части записи тоже ищутся, секретные нет. Дальше область полей: «Все», «Все кроме» или «Выбранные».

«Расширенные настройки» показывают, сколько блоков включено.

На Free этого блока нет, пока в настройках пространства «Ограничить просмотры» равно 0. Если число больше нуля, блок открывается и в нём только «Просмотры»: число из политики, его нельзя сменить, дальнейшее действие «Деактивировать», снять блок нельзя. Подсказка у выключателя: «Недоступно на текущем тарифе».

На Enterprise в блоке пять настроек. Если политика пространства уже включила блок, снять его в карточке нельзя.

| Блок | Что задаётся |
| --- | --- |
| «Просмотры» | «Количество просмотров:» и «Дальнейшее действие:»: «Деактивировать» или «Удалить капсулу». |
| «Время» | «Активировать:», «Деактивация по времени:», «Удаление по времени:». Готовые сроки: «Сразу», «Никогда», «Через 15 минут», «Через 1 час», «Через 6 часов», «Через 12 часов», «Через 24 часа», «После активации», или своя дата. Выключение раньше включения сохранить нельзя: «Время деактивации не может быть раньше времени активации». |
| «Доступ» | «Выберите пользователей». Чужой email добавляется кнопкой «Добавить …». Неверный адрес: «Неверный емейл». |
| «Пароль» | «Задайте пароль:» и «Колличество неудачных попыток:». При правке пустое поле («Оставьте пустым, чтобы не менять») оставляет прежний пароль. |
| «Подтверждение» | «Требовать подтверждение владельца перед показом». |

«Установить эти настройки по умолчанию для меня» запоминает блоки для следующих капсул.

:::tip
На Free капсула без политики просмотров создаётся без «Расширенных настроек». Срок, пароль, список получателей и подтверждение появляются на Enterprise.
:::

## Ссылка для получателя

Страница капсулы открывается без входа в хранилище. Заголовок: «Защищённая капсула Okkey». Получатель видит пароль («Капсула защищена паролем», кнопка «Разблокировать»), ожидание одобрения, лимит просмотров или срок. Это то, что включено в карточке.

Ссылку копируйте кнопкой «Копировать ссылку» и вставляйте целиком. В ней есть фрагмент `#key=`. Если его обрезать, страница пишет, что в ссылке нет ключа расшифровки.

Если политика «Только для участников», получатель видит «Для просмотра этой капсулы войдите в Okkey» и кнопку «Войти».

Неверный пароль: «Неверный пароль». Попытки кончились: «Лимит попыток исчерпан». Лимит просмотров: «Лимит просмотров этой капсулы исчерпан». Срок или выключенная капсула: «Капсула недоступна, не активирована или срок её действия закончился».

«Подтверждение» показывает владельцу окно «Подтвердите показ капсулы». В заявке: «Устройство», «Система», «Страна», «Город», «Время». Страна и город могут быть «Неизвестно». Кнопки: «Одобрить», «Запретить показ». «Добавить в чёрный список» закрывает этот email или IP для этой капсулы. Получатель в ожидании видит «Ожидание подтверждения владельца…». Отказ: «Владелец запретил показ этой капсулы».

## Как проверить

1. На Free создайте капсулу «Текст» без политики просмотров. Блока «Расширенные настройки» нет. Тост говорит, что ссылка скопирована. Откройте ссылку в другом браузере: текст виден без входа.
2. В «Настройки», «Капсулы» поставьте «Ограничить просмотры» равным 1. Новая капсула показывает «Просмотры» включёнными, число 1, действие «Деактивировать», выключатель не снимается. Второй просмотр ссылки пишет, что лимит исчерпан.
3. Выключите тип «Файл» в «Разрешить типы капсул». В новой капсуле этот тип недоступен.
4. На Enterprise включите «Пароль» и откройте ссылку. Страница просит «Пароль капсулы» до показа текста.
