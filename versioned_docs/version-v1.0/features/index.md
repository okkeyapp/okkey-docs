# Возможности

Четыре свойства ниже объясняют, почему сервер не читает ваши записи.

- [Q-Day ready](./qday) - гибридное шифрование новых записей, с постквантовой частью.
- [Максимальная защищённость](./security) - ключ из трёх долей, отдельный ключ у каждого сейфа.
- [Нулевое хранение](./zero-knowledge) - сервер хранит шифротекст, открытые секреты остаются у вас.
- [Открытый код, включая шифрование](./open-source) - шифрование опубликовано вместе с Okkey.

Пункты меню: «Все записи», «Капсулы», «Инструменты», «Настройки». «Мониторинг» есть на Enterprise.
