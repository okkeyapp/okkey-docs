# Предприятие

Тариф «Предприятие» - это self-hosted с большим набором функций. Ставите Okkey вы сами, по странице [Этапы установки](./free.md). Тариф после этого подключает сотрудник Okkey.

Это бета. Независимого аудита безопасности пока не было.

## Что даёт тариф

Цифры и полный список - на странице [Тарифы](../plans.md). Коротко, чем «Предприятие» отличается от тарифа «Бесплатный»:

| Возможность | «Предприятие» |
| --- | --- |
| Дополнительные участники | без предела |
| Общие сейфы | без предела |
| Мониторинг | да |
| Пользовательские роли и профили | да |
| Доверенные устройства и доверенные контакты | да |
| Расширенные настройки капсулы: срок, пароль и число попыток, доступ только участникам, подтверждение владельца | да |

Капсулы, файлы в записях, встроенные роли и профили, ключ восстановления, генератор, импорт и экспорт есть и на тарифе «Бесплатный». Потолка объёма хранилища на self-hosted нет уже на тарифе «Бесплатный».

На карточке в «Сменить тариф» среди строк есть «Неограниченное хранилище». Сравнивайте возможности по таблице на странице [Тарифы](../plans.md).

## Как запросить

1. Откройте «Настройки», «Сменить тариф». Кнопка «Отправить заявку» открывает окно «Заявка на лицензию». Текст окна: «Команда Okkey свяжется с вами по поводу лицензии для self-hosted.»
2. Укажите «Email для связи» и «Количество участников пространства». Нажмите «Отправить».

Письмо уходит на адрес `OKKEY_SALES_EMAIL` из файла `.env`. Его задают при [установке](./free.md). С одного пространства Okkey принимает не больше 3 заявок за скользящие 24 часа. Подробнее, включая тексты ошибок, на странице [Сменить тариф](../workspace/plan.md).

## Файл лицензии

Тариф «Предприятие» подключает сотрудник Okkey. Он выпускает файл лицензии под ваш сервер: для этого владелец пространства в «Настройки», «Сменить тариф» копирует отпечаток инстанса и передаёт его команде Okkey.

Полученный файл загружает только владелец пространства, в том же разделе «Сменить тариф». Проверка проходит на вашем сервере, постоянного обращения к порталу лицензий для работы не нужно.

«Публичный URL приложения» (его задают в мастере первого запуска на шаге «Сервер» или в «Настройки», «Почта», это же `PUBLIC_APP_URL`) должен совпадать с адресом, под который выпущена лицензия. На `localhost` лицензию не выпускают и не принимают.

Продление - новым файлом, его снова загружает владелец. В последние 30 дней до окончания срока в разделе тарифа показывается напоминание. Письма-напоминания за 30, 7 и 1 день уходят владельцу только если SMTP задан через переменные окружения `EMAIL_SMTP_HOST` и `EMAIL_FROM`. Настройки почты из мастера первого запуска или из «Настройки», «Почта» для этих писем пока не используются. Без такого SMTP в окружении остаётся только напоминание в интерфейсе.

Функции тарифа «Предприятие» включаются только после того, как владелец загрузит действующий файл лицензии. Без файла или если файл не принят, эти функции выключены. Когда сотрудник Okkey уже подключил тариф, владелец в «Сменить тариф» видит отпечаток инстанса и может загрузить файл, даже если лицензии ещё нет.

Подробности экрана - на странице [Сменить тариф](../workspace/plan.md).

## Обновления

Образы Okkey обновляются так же, как на тарифе «Бесплатный». Шаги - на странице [Обновление](../admin/upgrade.md). Enterprise обновляют через [Compose](../admin/upgrade.md#шаги) или офлайн-пакет, который выдаётся клиентам Enterprise вместе с релизом Enterprise. Для закрытой сети см. [изолированный режим](../admin/upgrade.md#изолированный-режим).

Внизу сайдбара у любого вошедшего видна версия. Окно «Обновление системы» открывается по ней. Строка «Enterprise» есть, когда модуль установлен: в окне видны версия и короткий SHA, когда установка его сообщает. Подробности по окну и ленте ядра - на странице [Обновление](../admin/upgrade.md#окно-в-интерфейсе).

## Когда лицензия заканчивается

Пространство переходит на тариф «Бесплатный». Данные остаются доступными. Общие сейфы и участники работают в пределах тарифа «Бесплатный»: один общий сейф и до 10 дополнительных участников. Функции тарифа «Предприятие» (расширенные настройки капсулы, пользовательские роли и профили, доверенные устройства и контакты, мониторинг) перестают получать обновления. Создавать и менять функции тарифа «Предприятие» нельзя, уже созданное можно смотреть и удалять.

Тот же текст на странице [Тарифы](../plans.md#когда-лицензия-enterprise-заканчивается).

## Как проверить

Три экрана в «Сменить тариф»:

1. Установка только «Бесплатный»: карточка «Предприятие» и кнопка «Отправить заявку»; в сайдбаре нет «Мониторинг».
2. Тариф «Предприятие» уже подключил сотрудник Okkey, но действующего файла ещё нет (или файл не принят / истёк): владелец видит отпечаток инстанса и загрузку файла; функции тарифа ещё выключены.
3. Действующий файл загружен: заголовок «Текущий тариф: Предприятие», функции тарифа включены.
