# Первая настройка

Пока в Okkey нет пользователей, первый аккаунт создаётся без письма. Почта для этого шага не нужна.

Когда аккаунт уже есть, вход по тому же адресу идёт через одноразовый код.

## Экраны

1. «Добро пожаловать в Okkey». Поле «Email», кнопка «Войти».
2. Если пользователи уже есть: «Код подтверждения», 6 цифр.
3. «Регистрация в Okkey». Поля: «Имя», «Фамилия», «Мастер-пароль», «Повторите мастер-пароль». Пароль не короче 4 символов, пароли должны совпасть. Кнопка «Зарегистрироваться».
4. «Сохраните ключ восстановления». Можно скопировать ключ или скачать PDF.

:::warning
Сохраните ключ восстановления до кнопки «Далее». После этого экран его больше не покажет, и сервер ключ не восстановит.
:::

Регистрация создаёт пространство «Личный» и «Личный сейф». Второе пространство создать нельзя. Тариф этой установки - Free. Enterprise настраивает сотрудник Okkey, см. [Тарифы](../plans).

Дальше откроется хранилище. Повторный вход на этом устройстве - экран «Мастер-пароль». В меню аккаунта: «Мои настройки», «Настройки устройства», «Выйти». Язык переключается в шапке. «Сменить сервер» есть в расширении.
