# Установка self-hosted

Self-hosted ставит Okkey на вашу машину. Шифрование остаётся на вашем устройстве, поэтому содержимое сейфов с сервера не прочитать.

Установка, которую вы делаете сами, работает на Free. Enterprise настраивает сотрудник Okkey. Что входит в каждый тариф, смотрите на странице [Тарифы](../plans.md).

Поддерживается только Docker Compose. Kubernetes и Helm запланированы и не входят в v1.0.0.

## С чего начать

1. Проверьте [требования](./requirements.md): Docker и место под данные.
2. Поставьте Okkey по [этапам установки](./free.md).
3. Создайте первый аккаунт в [первой настройке](../getting-started/first-setup.md).
