# Установка self-hosted

Self-hosted ставит Okkey на вашу машину. Шифрование остаётся на вашем устройстве, поэтому содержимое сейфов с сервера не прочитать.

Это бета. Независимого аудита безопасности пока не было.

Установка, которую вы делаете сами, работает на тарифе «Бесплатный». Тариф «Предприятие» подключает сотрудник Okkey. Что входит в каждый тариф, смотрите на странице [Тарифы](../plans.md).

Поддерживается только Docker Compose. Kubernetes и Helm запланированы и не входят в v1.0.0.

## Что выбрать

| Вариант | Когда он подходит |
| --- | --- |
| «Бесплатный» | Вы ставите Okkey сами. Есть капсулы, файлы в записях, один общий сейф и 10 дополнительных участников. |
| «Предприятие» | Нужны мониторинг, свои роли и профили, общие сейфы и участники без предела, расширенные капсулы и восстановление. Напишите команде Okkey. См. [Предприятие](./enterprise.md). |

Оба варианта работают на вашей машине. Сравнение — на странице [Тарифы](../plans.md).

## С чего начать

1. Проверьте [требования](./requirements.md).
2. Поставьте Okkey по [этапам установки](./free.md).
3. Если сайт должен открываться с других машин по имени, настройте [домен и TLS](./domain-tls.md).
4. Для писем и приглашений настройте [почту](./email.md).
5. Создайте первый аккаунт в [первой настройке](../getting-started/first-setup.md).

Копии данных, обновление и возврат к прошлой копии — в разделе [Администрирование](../admin/index.md).

## Как проверить

После установки веб открывается по адресу из установщика. На той же машине `http://127.0.0.1:4000/health` отвечает `"status": "ok"`. Команды проверки — на странице [Этапы установки](./free.md).
