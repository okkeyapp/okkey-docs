# Требования к серверу

Прод-установка идёт через Docker Compose. Клонировать репозиторий не нужно.

Нужны Docker, Docker Compose и место под базу, очередь и файлы. Число ядер и объём RAM установщик не задаёт.

## Что запускается

| Часть | Зачем |
| --- | --- |
| Веб | Интерфейс в браузере. |
| API | Принимает запросы и обновляет базу при старте. |
| Фоновые задачи | Удаляет просроченные записи и капсулы, отправляет почту. |
| Postgres | Пользователи, устройства, метаданные. |
| Redis | Сессии и очередь писем. |
| Хранилище файлов | Зашифрованные вложения. |

Порты по умолчанию: веб `8080`, API `4000`.
