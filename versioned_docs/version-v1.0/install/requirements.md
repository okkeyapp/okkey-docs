# Требования к серверу

Поддерживается только Docker Compose. Kubernetes и Helm запланированы и не входят в v1.0.0. Клонировать репозиторий для обычной установки не нужно.

Одинаковые требования у тарифа «Бесплатный» и тарифа «Предприятие». Тариф «Предприятие» подключает сотрудник Okkey уже после установки. См. [Предприятие](./enterprise.md).

## Программы

| Программа | Зачем |
| --- | --- |
| Docker Engine 28.0 или новее | Публикует порт API только на `127.0.0.1`. На более старом Engine этот адрес могли открыть другие машины в той же сети. |
| Плагин Docker Compose | Команда `docker compose version` должна выполняться. |
| `curl` и `bash` | Скачивают и запускают скрипт установки. |
| [cosign](https://docs.sigstore.dev/cosign/system_config/installation/) | Проверяет подписи образов `api`, `web` и `worker`. Без cosign установка останавливается. |

## Ресурсы

Установщик сам число ядер и объём диска не задаёт. В требованиях к первой стабильной версии для одной машины и небольшой команды указано:

- 2 vCPU;
- 4 ГБ RAM;
- 20 ГБ SSD под базу и файлы, без учёта копий.

Это ориентир. При росте числа людей и файлов места нужно больше.

Проверенные версии зависимостей в этой поставке: Postgres 16, Redis 7, хранилище файлов, совместимое с S3 (в Compose это MinIO).

## Что запускается

| Часть | Зачем |
| --- | --- |
| Веб | Интерфейс в браузере. Порт по умолчанию `8080` (`WEB_PORT`). |
| API | Принимает запросы и обновляет базу при старте. Порт по умолчанию `4000` (`API_PORT`), только на `127.0.0.1`. |
| Фоновые задачи | Отправляет почту, удаляет просроченные записи и капсулы. |
| Postgres | Пользователи, устройства, метаданные. |
| Redis | Сессии и очередь писем. |
| Хранилище файлов | Зашифрованные вложения. |

С другой машины порт API напрямую не открыть. Для доступа по сети нужен [домен и TLS](./domain-tls.md).

## Как проверить

На машине, где будет Okkey:

```bash
docker --version
docker compose version
command -v curl
command -v bash
command -v cosign
```

В выводе Docker должна быть версия 28 или выше. Каждая из остальных команд тоже должна что-то напечатать.
