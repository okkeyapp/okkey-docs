# Поля и секции

Запись собирается из названия, тегов, секций и полей. Секретные поля по умолчанию скрыты, чтобы их не было видно на открытой карточке.

В карточке поле «Название записи» (плейсхолдер «Название»), «Теги», «Загрузить иконку» (JPG или PNG, иначе «Выберите изображение JPG или PNG.»). Куда сохранить: подпись «сохранить в», сейф с плейсхолдером «Выберите сейф», папка «Без папки». Кнопки «Сохранить» и «Отмена». Свои поля и секции: «Добавить поле», «Добавить секцию с полем».

Пресетные секции идут первыми. Свои секции можно переставлять вместе с полями. Заголовок своей секции: плейсхолдер «Добавить название». Удаление секции - «Удалить секцию», если секция это позволяет. Удаление поля - «Удалить поле». Обязательные поля пресета (логин, пароль, первый URL, имя API, секреты API, номер карты, срок, CVC, имя и фамилия личных данных) так не удаляются.

Поле «Файл» и категория «Защищённые файлы» появляются, когда в пространстве включено «Разрешить файлы в записях». Эта настройка есть на Enterprise.

## Типы, которые можно добавить

Подписи типов, которые можно добавить:

| Тип |
| --- |
| «Текст» |
| «Email» |
| «Телефон» |
| «Адрес» |
| «Дата» |
| «URL сайта» |
| «Выбор» |
| «Многострочный текст» |
| «Секрет» |
| «TOTP» |
| «Коды восстановления» |
| «Файл» |

«Пароль» и CVC уже стоят в готовых категориях «Логин / пароль» и «Банковская карта».

Адрес раскладывается на «Улица», «Дом», «Квартира», «Город», «Регион», «Почтовый индекс», «Страна». Страна ищется: «Поиск страны», пусто - «Страны не найдены».

Файл: «Загрузить файл», «Удалить файл». Лимит размера и расширения - из настроек пространства. Подсказка показывает максимум.

Дата открывает календарь.

TOTP показывает код и срок. В меню поля: «Ввести новый TOTP-секрет».

Коды восстановления: «Показать коды» / «Скрыть коды». В просмотре можно отмечать использованные.

Секрет по умолчанию скрыт. «Показать значение» открывает его, если у поля нет своего меню.

## Шестерёнка поля

Шестерёнка открывает дополнительные настройки поля. Состав меню зависит от типа.

| Поле | Пункты |
| --- | --- |
| Фиксированный пароль логина | «Показать пароль» / «Скрыть пароль», «Генератор». |
| Настраиваемый секрет | Вид: «Пароль», «Однострочный секрет», «Многострочный секрет». Затем показ и «Генератор». Для пароля подписи показа - «Показать пароль», для секрета - «Показать секрет». |
| TOTP | «Ввести новый TOTP-секрет». |
| URL в секции сайтов логина | «Заполнять на всём сайте», «Заполнять только на этом URL», «Без автозаполнения». От этого зависит [расширение](../apps/extension). |
| Телефон | «Включить маску» / «Отключить маску». Маска прячет номер, пока её не снимут. |
| CVC/PIN | «Показать CVC/CVV» / «Скрыть CVC/CVV». |
| Выбор | «Войти в режим редактирования» / «Выйти из редактирования». В режиме правки пункты - «Одно значение на строку». Пустой список: «Нет пунктов». |
| Многострочный текст | «Включить копирование по клику» / «Отключить копирование по клику». Выключенное копирование не даёт скопировать весь текст одним нажатием. |

Генератор в поле: длина 4–128, наборы «A-Z», «a-z», «0-9», «!@#$%^&*», «Надёжность:», «Время взлома:», «Сгенерировать снова», «Вставить», «Отмена».

Копирование поля в карточке - «Копировать». Секреты в поиск списка не попадают.

Выход из новой записи без сохранения спрашивает «Выйти без сохранения?» - «Все введённые данные будут потеряны.» Кнопка «Продолжить».

:::tip
Режимы автозаполнения URL задаются шестерёнкой поля. От них зависит, подставит ли расширение пароль на всём сайте или только на этом адресе.
:::
