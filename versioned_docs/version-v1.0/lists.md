# Списки записей

Список «Все записи» собирается на вашем устройстве из расшифрованных записей. Поиск не уходит на сервер и не смотрит секреты. Пусто: «Нет записей». Пока данные едут: «Загрузка записей». Длинный список догружается по мере прокрутки.

Поиск, фильтр и сортировка - три разных механизма. Фильтр не заменяет поиск.

## Поиск

Поле «Поиск...», очистка - «Очистить поиск».

Пока в поле есть текст, сейф, вид сейфа, папка и категория в выборку не входят: ищутся все загруженные записи, затем на них ещё накладывается фильтр (избранное, архив и так далее). Сортировка при поиске сначала по весу совпадения, потом по выбранной сортировке.

Совпадение в названии важнее совпадения в адресе. Первый адрес важнее следующего.

Запрос, который начинается с `#` и после решётки содержит текст, ищет тег целиком без учёта регистра. Другие поля при таком запросе не участвуют. Чужой тег скрывает запись.

Секреты, пароли и заметки в этот вес не входят. Описание строки на экране есть, но поиском не считается. Поиск внутри окна капсулы - другой: он смотрит незашифрованные поля пресетных секций.

Тег можно выбрать и из фильтра, пункт «Теги»: поиск «Поиск по тегам», пусто - «Теги не найдены». Выбор подставляет в строку поиска `#тег`.

:::tip
Поиск по тексту сбрасывает сейф и папку. Если нужно остаться внутри сейфа, пользуйтесь фильтром, а не строкой поиска.
:::

## Фильтры

Кнопка с подписью для доступности «Фильтр списка записей». В меню только четыре режима. Остальное - область (сейф, папка, категория, тег) или фильтр, который пришёл из мониторинга.

Сброс области - красная кнопка на чипе. Она убирает сейф, папку, поиск и фильтр. Сортировка и открытая запись остаются. Тот же смысл у «Все записи» в сайдбаре.

| Пункт | Что остаётся |
| --- | --- |
| «Все записи» | Не удалённые и не архивные. |
| «Избранные» | Те же, плюс отмеченные избранными. Архив и корзина сюда не попадают. |
| «Архивные» | Архив, не удаление. |
| «Недавно удалённые» | Помеченные удалёнными. Они лежат здесь, пока не выйдет срок [хранения](./settings/workspace#записи). |

Области в том же меню:

| Область | Зачем |
| --- | --- |
| «Сейфы» | Один сейф. Список сужается до его записей, если нет текстового поиска. |
| «Папки» | Ветка ваших личных папок. |
| «Категории» | Только записи этой категории. Пусто: «Нет категорий с записями». Категория не комбинируется с уже набранным поиском: поиск важнее. |
| «Теги» | Превращает выбор в поиск `#тег`. |

«Личный» и «Общие» на странице мониторинга выбирают набор сейфов. В списке они показаны чипом.

Фильтры мониторинга в меню фильтра не перечислены. Их ставит кнопка «Показать» на [мониторинге](./monitoring). «Мониторинг» доступен и на Free, и на Enterprise. Если параметр всё же есть в адресе, список оставляет неархивные и неудалённые записи из отчёта:

| Фильтр в адресе | Подпись, которую показывает триггер |
| --- | --- |
| reused | «Повторно используемые пароли» |
| strong | «Сильные пароли» |
| medium | «Средние пароли» |
| weak | «Слабые пароли» |
| stale | «Устаревшие пароли» |
| compromised | «Скомпрометированные пароли» |
| 2fa-gap | «2FA доступны, но не настроены» |
| passkey-gap | «Passkeys доступны, но не настроены» |

Кнопка «Показать» подписывает фильтр заголовком карточки мониторинга.

Пока отчёт мониторинга грузится, список ждёт его, если активен такой фильтр. Карточка passkey сейчас всегда пустая, поэтому «Показать» по ней даст пустой список.

## Сортировка

Кнопка «Сортировка списка записей». По умолчанию «Сначала новые».

Группа «По дате:»:

| Пункт | Порядок |
| --- | --- |
| «Сначала новые» | По времени обновления записи. Секции списка - месяц и год. |
| «Сначала старые» | По возрастанию того же поля. |

Группа «По алфавиту:»:

| Пункт | Порядок |
| --- | --- |
| «Алфавит» | По названию. Порядок букв совпадает с русским алфавитом и в английском интерфейсе. |
| «Обратный алфавит» | Обратный порядок. |

Секции алфавита - первая буква названия в верхнем регистре языка интерфейса. Если первый знак не буква, секция `#`. `#` в порядке секций всегда раньше букв. Внутри секции порядок строк - тот же, что у сортировки.
