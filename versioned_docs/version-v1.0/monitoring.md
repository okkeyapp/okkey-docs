# Мониторинг

«Мониторинг» есть в боковом меню на Enterprise. На Free пункта нет. Страница смотрит записи, которые вам доступны в текущем пространстве, и показывает слабые, повторные и другие проблемные пароли. Подсчёт идёт на вашем устройстве. На карточке бейдж «Beta».

Текст страницы: оценка считается по доступным записям, анализ выполняется локально и не собирает статистику о данных.

Если паролей нет, заголовок «Пока нечего анализировать» и кнопка «Перейти к записям». Если проблем не нашлось, заголовок «Всё в порядке».

«Показать» открывает список записей с уже выбранным фильтром. Область сейфов: «Все сейфы», «Личный», «Общие».

## Карточки

| Карточка | О чём она |
| --- | --- |
| «Общий показатель» | Общий уровень по доступным записям пространства. Подписи уровня: «Отлично», «Хорошо», «Средне», «Плохо». |
| «Надёжность паролей» | Доли «сильные», «средние» и «слабые». Счётчик подписан «Паролей». |
| «Повторно используемые пароли» | Один пароль в нескольких аккаунтах. |
| «Слабые пароли» | Пароли, которые проще подобрать. |
| «Скомпрометированные пароли» | Пароли из известных утечек. Проверка идёт через Have I Been Pwned: на сервер уходит только префикс SHA-1 хеша, полный пароль устройство не передаёт. |
| «Устаревшие пароли» | Пароль не менялся больше года. |
| «2FA доступны, но не настроены» | У части аккаунтов можно включить второй фактор, а в записи его нет. |
| «Passkeys доступны, но не настроены» | Сервис из записи поддерживает passkey, а в записи его нет. |

Справочник доменов для 2FA и passkeys подписан как открытый «каталог Okkey domain-capabilities».

«Показать» ставит фильтр списка. В обычном меню фильтра этих пунктов нет: они приходят со страницы мониторинга. См. [Списки записей](./items/lists.md).

## Как проверить

1. На Free пункта «Мониторинг» в сайдбаре нет.
2. На Enterprise откройте «Мониторинг». Без паролей виден «Пока нечего анализировать» и «Перейти к записям».
3. При паролях видны карточки из таблицы и бейдж «Beta». «Показать» открывает список с фильтром карточки. «Все сейфы», «Личный» и «Общие» меняют набор сейфов.
