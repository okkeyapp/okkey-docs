# Тарифы

У self-hosted два тарифа: «Бесплатный» и «Предприятие». Вы ставите Okkey сами, и такая установка работает на тарифе «Бесплатный». Тариф «Предприятие» подключает сотрудник Okkey. Чтобы получить тариф «Предприятие», напишите команде Okkey из раздела [«Сменить тариф»](./workspace/plan.md).

В self-hosted у владельца одно пространство. Это верно и на тарифе «Бесплатный», и на тарифе «Предприятие».

## Что входит

Цифры ниже взяты из матрицы тарифов self-hosted. Личный сейф в предел общих сейфов не входит. Владелец в предел участников не входит.

| Возможность | «Бесплатный» | «Предприятие» |
| --- | --- | --- |
| Капсулы, включая файл | да | да |
| Файлы в записях | да | да |
| Лимит просмотров капсулы из настроек пространства | да | да |
| Расширенные настройки капсулы: срок, пароль и число попыток, доступ только участникам, подтверждение владельца | нет | да |
| Встроенные роли («Владелец», «Админ», «Пользователь») и профили («Простой», «Расширенный») | да | да |
| Пользовательские роли и профили | нет | да |
| Ключ восстановления | да | да |
| Доверенные устройства и доверенные контакты | нет | да |
| Общие сейфы | 1 | без предела |
| Дополнительные участники | 10 | без предела |
| Генератор, импорт и экспорт | да | да |
| Мониторинг | нет | да |
| Потолок объёма хранилища | нет | нет |

На карточке тарифа «Предприятие» в «Сменить тариф» среди строк есть «Неограниченное хранилище». Потолка объёма на self-hosted нет уже на тарифе «Бесплатный». Сравнение возможностей смотрите в таблице выше.

## Когда лицензия тарифа «Предприятие» заканчивается {#когда-лицензия-enterprise-заканчивается}

Пространство переходит на тариф «Бесплатный». Данные остаются доступными. Общие сейфы и участники работают в пределах тарифа «Бесплатный»: один общий сейф и до 10 дополнительных участников. Функции тарифа «Предприятие» (расширенные настройки капсулы, пользовательские роли и профили, доверенные устройства и контакты, мониторинг) перестают получать обновления. Их можно просматривать и удалять, но создавать новое и менять существующее нельзя.

## Как проверить

1. На тарифе «Бесплатный» в сайдбаре нет «Мониторинг». В «Настройки», «Сейфы» можно создать один общий сейф, второй не сохраняется.
2. В «Участники» приглашение проходит, пока дополнительных участников и живых приглашений не больше 10.
3. В «Роли» и «Профили» видны встроенные строки. Блок пользовательских ролей и профилей пишет, что функция недоступна на текущем тарифе.
4. В «Мои настройки», «Восстановление» есть «Ключ восстановления». «Доверенные устройства» и «Доверенные контакты» на тарифе «Бесплатный» не включаются.
