# Настройки

Личные настройки и устройство открываются из меню аккаунта: «Мои настройки» и «Настройки устройства».

Правила пространства открываются из пункта сайдбара «Настройки».

## Меню аккаунта

| Пункт | Куда |
| --- | --- |
| «Основное» | [Личные](./personal#основное) |
| «Мастер пароль» | [Личные](./personal#мастер-пароль) |
| «Методы входа» | Пункт в меню не показывается. См. [личные](./personal#методы-входа). |
| «2ФА аутентификация» | [Личные](./personal#двухфакторная-аутентификация) |
| «Восстановление» | [Личные](./personal#восстановление) |
| «Мои устройства» | [Устройства](./devices#мои-устройства) |
| «Персонализация», «Безопасность», «Разблокировка» | [Устройства](./devices) |

## Настройки пространства

| Раздел | Страница |
| --- | --- |
| «Основное», внутри него «Записи» и «Капсулы» | [Пространство](./workspace#основное) |
| «Роли» | [Пространство](./workspace#роли) |
| «Профили» | [Пространство](./workspace#профили) |
| «Участники» | [Пространство](./workspace#участники) |
| «Сейфы» | [Пространство](./workspace#сейфы) |

Кто видит раздел настроек пространства, задаёт роль. Встроенные роли: «Владелец», «Админ», «Пользователь». У «Пользователя» нет доступа к настройкам пространства.
