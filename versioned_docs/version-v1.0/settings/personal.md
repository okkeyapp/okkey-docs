# Личные настройки

«Мои настройки» в меню аккаунта. Окно открывается по своему адресу `?popup=settings`. Здесь профиль, мастер-пароль и способы вернуть доступ.

На странице «Основное» сверху показан блок «Защищённость аккаунта».

## Основное

Имя, почта, язык и регион профиля.

| Настройка | Как изменить |
| --- | --- |
| «Имя», «Фамилия» | Поля профиля. |
| «Сменить email» | Открывает «Смена email». |
| «Язык» | Русский и английский. Тот же переключатель «Язык» есть в шапке веба и в расширении. |
| «Регион проживания» | Список с поиском «Поиск региона...». |

Тема и цвет браузера задаются в [персонализации устройства](./devices#персонализация).

## Мастер пароль

Мастер-пароль открывает хранилище. Сервер его не хранит. Зоны повторного подтверждения задаются в этом окне. Адрес пункта: `?popup=settings|vault`.

На странице видно, когда пароль задавали. «Сменить» открывает «Смена мастер-пароля»: текущий пароль и новый пароль дважды.

«Запрашивать мастер-пароль» отмечает зоны, где нужно подтвердить доступ ещё раз.

- Разделы: «Записи», «Капсулы», «Мониторинг», «Инструменты», «Настройки хранилища», «Мои настройки».
- Окна: «Записи», «Капсулы», «Сейфы», «Папки».
- Действия: «Удаление».

Пока зона не подтверждена, экран называется «Подтвердите доступ».

Время бездействия, блокировка при сне, буфер, биометрия и PIN задаются в [настройках устройства](./devices). Они остаются на этом устройстве.

## Методы входа

Пункт «Методы входа» в меню не показывается. Вход идёт по email и коду из письма. Дополнительно можно включить [двухфакторную аутентификацию](#двухфакторная-аутентификация).

## Двухфакторная аутентификация

Второй фактор нужен, чтобы кода из почты было мало для входа. Доступно на Free и на Enterprise.

| Настройка | Что делает |
| --- | --- |
| «Приложение-аутентификатор» | Одноразовые коды из приложения, например Google Authenticator. |
| «Резервные коды» | Одноразовые коды на случай, если приложения нет под рукой. |
| «Отключение 2ФА» | Просит код из приложения-аутентификатора. |

## Восстановление

Настройте способ восстановления заранее. Если мастер-пароль забыт, сервер сам его не подберёт.

| Способ | Тариф | Как включить |
| --- | --- | --- |
| «Ключ восстановления» | Free и Enterprise | Включите или перевыпустите ключ. Тот же ключ предлагается при регистрации. |
| «Доверенные устройства» | Enterprise | Нужно минимум два доверенных устройства, одно из них текущее. Иначе появится просьба добавить ещё одно устройство. |
| «Доверенные контакты» | Enterprise | Минимум 3 подтверждённых контакта. Контакт уже должен быть пользователем Okkey. |
| «Я доверенный контакт» | Enterprise | Список аккаунтов, которым вы можете помочь. Оттуда можно выйти. |

На Free «Доверенные устройства» и «Доверенные контакты» недоступны. Чтобы получить Enterprise, напишите команде Okkey. См. [Тарифы](../plans).

Пока хранилище открыто, доли для подтверждённых контактов готовятся сами. Порог - 3 контакта. Запрос на восстановление живёт 1 час.

:::warning
Запрос на восстановление живёт 1 час. После этого его нужно создать заново.
:::

### Доверенные устройства

Страница «Забыли мастер-пароль?», вариант «Используйте другое устройство, которому уже доверяет аккаунт».

1. Нажмите «Запросить восстановление через устройство».
2. На другом доверенном устройстве с открытым хранилищем подтвердите запрос «Запрос на восстановление аккаунта». Закрыть окно без решения нельзя.
3. В карточке видны имя устройства, клиент, ОС, дата, IP и страна. Подтверждайте только знакомое устройство.
4. «Подтвердить» или «Отклонить». В дополнительных действиях есть «Заблокировать устройство».
5. После подтверждения задайте «Новый мастер-пароль» и нажмите «Восстановить доступ».

Если запрос отклонён или истёк, начните заново. Если устройство заблокировали, войти с этого браузера больше нельзя.

### Доверенные контакты

Вариант «Попросите помощи у подтверждённых доверенных контактов».

1. Нажмите «Запросить помощь контактов».
2. Контакт с открытым хранилищем нажимает «Выдать долю» в окне «Помочь контакту восстановить доступ».
3. Когда долей достаточно, задайте новый мастер-пароль и нажмите «Восстановить доступ».
4. Запрос можно «Отозвать».

Если открыть хранилище, пока запрос к контактам ещё ждёт, запрос отменяется. После смены мастер-пароля доли готовятся заново при следующем открытии хранилища.
