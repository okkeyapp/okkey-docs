# Экспорт

Экспорт собирает файл у вас в браузере, из уже открытого хранилища. Файл годится для резервной копии или переноса в другой сервис.

- «Выберите сейф для экспорта записей». Без права экспорта из этого сейфа команда недоступна.
- «Формат».
- «Включить папки» записывает пути папок, чтобы импорт мог их восстановить. Не у всех форматов пути папок поддерживаются (см. таблицу).
- «Защитить паролем» шифрует файл. Поле «Пароль экспорта». Пароль доступен у форматов, где в таблице колонка «Пароль» отмечена «да».

Перед кнопкой текст, сколько записей уйдёт в файл. Ход: «Подготовка записей…», «Сборка файла экспорта…». Успех: «Экспортировано записей: N → файл». Ошибка: «Не удалось выполнить экспорт».

| Формат | Расширение | Пароль | Папки | Вложения |
| --- | --- | --- | --- | --- |
| Okkey (json) | json | да | да | нет |
| Okkey (csv) | csv | нет | да | нет |
| Okkey ZIP (с файлами) | zip | да | да | да |
| 1Password (csv) | csv | нет | нет | нет |
| 1Password (1pux) | 1pux | нет | да | нет |
| Bitwarden (json) | json | да | да | нет |
| Bitwarden (csv) | csv | нет | да | нет |
| Bitwarden ZIP (с файлами) | zip | да | да | да |
| Chrome (csv) | csv | нет | нет | нет |
| Microsoft Edge (csv) | csv | нет | нет | нет |
| Firefox (csv) | csv | нет | нет | нет |
| Safari (csv) | csv | нет | нет | нет |
| LastPass (csv) | csv | нет | да | нет |
| NordPass (csv) | csv | нет | да | нет |
| RoboForm (csv) | csv | нет | да | нет |
| KeePass 2 (xml) | xml | нет | да | нет |
| Kaspersky Password Manager (txt) | txt | нет | нет | нет |
| Kaspersky / My Kaspersky (csv) | csv | нет | нет | нет |
| Yandex Browser (csv) | csv | нет | нет | нет |
| Passwork (json) | json | нет | да | нет |
| Custom CSV | csv | нет | да | нет |

Yandex Browser (zip) можно только импортировать. В списке экспорта его нет. Названия ZIP Okkey и Bitwarden в интерфейсе содержат «с файлами» и на английском языке тоже.

Экспорт собирает файл в браузере из открытого хранилища. Пароль экспорта задаётся отдельно и нужен при импорте этого файла.

:::warning
Запомните пароль экспорта отдельно от мастер-пароля. Им открывается зашифрованный файл при импорте.
:::
