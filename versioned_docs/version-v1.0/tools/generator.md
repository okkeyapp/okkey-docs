# Генератор

Три генератора: «Пароль», «Кодовая фраза», «Имя пользователя». Они одинаково работают в вебе, в расширении и на странице сайта. Кнопки «Сгенерировать заново» и «Скопировать сгенерированное значение». Подробности окна расширения - в [браузерном расширении](../apps/extension.md).

Пароль собирается средствами браузера. Настройки генератора запоминаются в этом браузере и в сейф не записываются.

## Пароль

Длина 4–128, по умолчанию 16. Наборы по умолчанию: A-Z включены, a-z включены, 0-9 включены, символы `!@#$%^&*` выключены. Подписи в карточке записи те же: «A-Z», «a-z», «0-9», «!@#$%^&*», «Символов: N». Рядом «Надёжность:» и «Время взлома:». Время - оценка по энтропии. Подписи шкалы: «Мгновенно», «Часы», «Дни», «Месяцы», «Годы», «Десятилетия», «Века», «Никогда». Шкала показывает оценку по энтропии.

Тот же генератор открывается шестерёнкой у поля пароля в записи: «Генератор», затем «Вставить» или «Отмена».

## Кодовая фраза

Слова из списка EFF large. По умолчанию 3 слова, разделитель `-`, без заглавных и без цифры. Диапазон слов: 3–20. «С заглавной буквы» поднимает первую букву каждого слова. «Включить цифру» дописывает одну цифру 0–9 к случайному слову. «Разделитель» - один символ; если ввести больше, берётся первый, пустой заменяется на `-`.

## Имя пользователя

Одно слово из того же списка. «С заглавной буквы». «Включить число» дописывает 4 цифры от 0000 до 9999. По умолчанию оба выключателя сняты.
