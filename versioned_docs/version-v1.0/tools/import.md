# Импорт

Импорт переносит записи из другого менеджера в выбранный сейф. Поддерживаются стандартные форматы и файлы популярных менеджеров паролей.

Поля:

- «Выберите сейф для импорта записей» - запись пойдёт в выбранный сейф. Нет права писать: «Нет доступа для записи в выбранный сейф».
- «Формат», поиск «Поиск формата», пусто: «Формат не найден».
- Способ ввода: «Файл» или «Текст». «Загрузить файл», «Удалить файл», для текста - «Вставьте содержимое экспорта».
- «Импортировать папки» создаёт дерево папок и раскладывает записи по ним. Папки личные, см. [Папки](../items/folders.md).

Если файл закрыт паролем экспорта: окно «Пароль экспорта», «Разблокировать». Неверный пароль: «Неверный пароль экспорта».

Ход: «Разбор файла…», затем «Импорт N/M: название». Успех: «Импортировано записей: N. Пропущено: M.» Часть записей могла не попасть: «Часть записей не импортирована (N).» Пустой разбор: «Не найдено записей для импорта».

Для ZIP с вложениями: архив может быть большим, каждое вложение ограничено размером из настроек пространства, и загружаются только форматы, разрешённые в настройках.

:::note
Файлы из ZIP попадут в записи, только если включено «Разрешить файлы в записях». Настройка есть на Free и на Enterprise.
:::

| 1Password (csv) | csv | да | | |
| 1Password (1pux) | 1pux, zip | нет | да | |
| Bitwarden (json) | json | да | да | |
| Bitwarden (csv) | csv | да | да | |
| Bitwarden ZIP (с файлами) | zip | нет | да | |
| Chrome (csv) | csv | да | | |

| Safari (csv) | csv | да | | |

Незнакомый формат при разборе считается Custom CSV.
