# Инструменты

Пункт сайдбара «Инструменты» создаёт пароль или переносит записи, не выходя из хранилища. В меню три раздела: «Генератор», «Импорт», «Экспорт».

Генератор, импорт и экспорт доступны на Free. Файлы внутри ZIP сохраняются, если в пространстве включено «Разрешить файлы в записях». Эта настройка есть и на Free. Как её включить, смотрите в [настройке записей](../workspace/index.md#записи).
