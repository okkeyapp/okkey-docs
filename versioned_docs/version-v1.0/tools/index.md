# Инструменты

Пункт сайдбара «Инструменты» создаёт пароль или переносит записи, не выходя из хранилища. В меню три раздела: «Генератор», «Импорт», «Экспорт».

Генератор, импорт и экспорт доступны на Free и на Enterprise. Файлы внутри ZIP сохраняются, если в пространстве включено «Разрешить файлы в записях». На self-hosted эта настройка есть и на Free. Как её включить, смотрите в [настройке записей](../workspace/index.md#записи).

## Генератор

Пароль, кодовая фраза и имя пользователя: [Генератор](./generator.md).

## Импорт

Перенос записей из файла в выбранный сейф: [Импорт](./import.md).

## Экспорт

Файл с записями для резервной копии или переноса: [Экспорт](./export.md).

## Как проверить

1. Откройте «Инструменты». В меню три пункта, и ни один не пишет «Этот инструмент скоро появится.»
2. На Free генератор сразу выдаёт пароль, импорт и экспорт открываются без примечания про тариф.
