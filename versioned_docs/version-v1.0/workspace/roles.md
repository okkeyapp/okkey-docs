# Роли

Роль выдаёт доступ к разделам настроек пространства. Доступ к записям задаётся в [профилях](./profiles.md).

Встроенные роли менять и удалять нельзя:

| Роль | Доступ |
| --- | --- |
| «Владелец» | Уникальные права. Владельца нельзя пригласить, сменить ему роль или удалить из участников. |
| «Админ» | Все разделы настроек. |
| «Пользователь» | Без доступа к настройкам пространства. |

Разделы в таблице разрешений: «Основное», «Записи», «Капсулы», «Роли», «Профили», «Участники», «Сейфы».

«Пользовательские роли» есть на Enterprise. На Free вместо редактора показано примечание, что функция недоступна. Чтобы получить Enterprise, напишите команде Okkey.

В редакторе роли задаются «Название» и «Описание». Новая роль начинается без разрешений.

Уровень доступа: «Все» - ко всем объектам, «Свои» - только к объектам, которые создал этот участник, «Нет» - без разрешения. Создание включается отдельно.

Если снять просмотр, остальные действия по этому разделу тоже снимаются. Удаление своей роли переводит её участников на роль «Пользователь».
